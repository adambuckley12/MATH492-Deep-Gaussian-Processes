1 Introduction

Gaussian processes (GPs) provide a non-parametric framework for Bayesian inference, allowing for both predictions and uncertainty estimates. The flexibility of GPs comes from their kernel functions, which encode prior assumptions about function structure.

However, the expressiveness of a standard GP is limited by its kernel (Pravesh and Roi 2020). Choosing an appropriate kernel often requires domain expertise and trial and error, and a fixed kernel may fail to capture the complex, multi-scale structure present in real data. This motivated Deep Gaussian Processes (DGPs) (Damianou and Lawrence 2013), which compose multiple GP layers into a hierarchy that can learn rich representations automatically.

DGPs stack multiple GP layers so that each layer’s output becomes the next layer’s input. This composition allows the model to learn features at multiple levels of abstraction — much like deep neural networks — while retaining the principled uncertainty quantification of the GP framework. The price of this flexibility is tractability: although each layer is individually Gaussian, the composition produces a non-Gaussian joint distribution over latent functions, making exact inference intractable.

This dissertation provides an exploration of Gaussian Processes and Deep Gaussian Processes. We begin by deriving standard GP regression from first principles, show how composing these GPs into deep layered hierarchies leads to greater expressiveness at the cost of tractability, and then develop the variational inference needed to train these models at scale.

Finally, we apply DGPs and GPs to real-world datasets within finance, both credit-card default prediction and mortgage default prediction. We discuss advantages, limitations and tradeoffs between DGP structures, and demonstrate their ability to capture complex patterns and provide calibrated uncertainty estimates that are crucial for risk based decision making. We compare GP based models to classical machine learning (ML) models, and show that GP based models lead to better calibrated uncertainty estimates.

We begin by deriving the theory of standard GPs.

2 Towards Gaussian Processes

The problem in supervised machine learning is inferring functional relationships between input variables and observed outputs from a set of training examples. Given dataset \(\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^n\) where \(\mathbf{x}_i \in \mathbb{R}^D\) is an input vector and \(y_i \in \mathbb{R}\) is the corresponding output, we aim to learn some function \(f: \mathbb{R}^D \to \mathbb{R}\) that represents the underlying mapping \(y = f(\mathbf{x}) + \epsilon\), where \(\epsilon\) is a noise term.

In a classical frequentist approach, we typically define the function \(f\) as a parametric model and estimate it by using a finite set of parameters \(\mathbf{w}\). For example, in linear regression we have \(f(\mathbf{x}) = \mathbf{w}^\top \mathbf{x}\), and we aim to find the best estimate \(\hat{\mathbf{w}}\) such that \(y_i \approx \hat{\mathbf{w}}^\top \mathbf{x}_i\) for all \(i\). Within Bayesian statistics, we place a prior distribution on the parameters \(\mathbf{w}\), and then compute a posterior distribution \(p(\mathbf{w} \mid \mathcal{D})\) that captures updated beliefs about the parameters after observing the data (Bishop 2006; Murphy 2013).

In these so-called parametric models, the function \(f\) is fully specified by a finite set of parameters \(\mathbf{w}\). This number and structure of parameters is fixed in advance, and therefore the function space of \(f\) is limited by the choice of model. Further to this, the choice of parameters is often required before observing the data, and therefore requires domain expertise to select an appropriate model.

In contrast to frequentist approaches that specify a parametric model and estimate its parameters via maximum likelihood estimation (MLE) (Bishop 2006), GPs place a prior directly on an infinite-dimensional function space (Rasmussen and Williams 2008; D. J. MacKay 1998; Williams and Rasmussen 1995). Observed data then reduces uncertainty, yielding a final posterior distribution that captures the updated beliefs about the function.

This section outlines the theory of GPs for regression tasks, starting from the weight-space view of Bayesian linear regression and building up to the function-space view of GPs.

2.1 The Weight Space View

Before moving to the full function space perspective, it is helpful to build intuition through a finite-dimensional parametric approach. The weight space view treats regression as Bayesian inference over a weight vector. We show how the the structure of the resulting predictive distribution can be expressed in terms of inner products between inputs, which naturally motivates the transition into Gaussian processes (Rasmussen and Williams 2008; D. J. MacKay 1998).

We begin with a linear model of the form \[ f(\mathbf{x}) = \mathbf{x}^\top \mathbf{w}, \tag{1}\]

where \(\mathbf{w} \in \mathbb{R}^D\) is a weight vector. To make this more general, we consider an expansion of basis functions (Bishop 2006) \[ f(\mathbf{x}) = \sum_{j=1}^{M} w_j \phi_j(\mathbf{x}) = \boldsymbol{\phi}(\mathbf{x})^\top \mathbf{w}, \tag{2}\]

where \(\boldsymbol{\phi}(\mathbf{x}) = [\phi_1(\mathbf{x}), \ldots, \phi_M(\mathbf{x})]^\top\) is a vector of basis functions, which maps the input to an \(M\)-dimensional feature space, with weights \(\mathbf{w} = [w_1, \ldots, w_M]^\top\). This becomes more general than the simple linear model, allowing the modeling of non-linear relationships through the choice of basis functions \(\phi_j(\cdot)\), without breaking linearity in the parameters \(\mathbf{w}\).

Given some training data \(\mathcal{D}\), our goal is to learn a set of weights \(\mathbf{w}\) that best describes the data - which we call \(\hat{\mathbf{w}}\). A common approach is to use maximum likelihood estimation (MLE) (Bishop 2006; Murphy 2013), which finds the single best set of weights that maximises the likelihood of the observed data. However, this ignores how it is possible for different weight vectors to explain the observed data equally well, but make very different predictions in unobserved region. MLE can also lead to overfitting, where the model fits the training data too closely and fails to generalise to new data.

This motivates a Bayesian approach.

2.2 Bayesian Linear Regression

2.2.1 Prior and Likelihood

A Bayesian approach addresses these issues by placing a prior distribution over \(\mathbf{w}\), which turns the the problem into so-called Bayesian linear regression (Bishop 2006; Gelman et al. 2025). A natural choice is a zero-mean Gaussian prior: \[ p(\mathbf{w}) = \mathcal{N}(\mathbf{w} \mid \mathbf{0}, \Sigma_p), \tag{3}\]

where \(\Sigma_p \in \mathbb{R}^{M \times M}\) is the prior covariance matrix. A common prior is \(\Sigma_p = \sigma_w^2 \mathbf{I}\), which gives independent, identically distributed, (i.i.d.) Gaussian weights with variance \(\sigma_w^2\) (D. J. C. MacKay 1992).

When modelling each observation as \(y_i = f(\mathbf{x}_i) + \epsilon_i\), where \(\epsilon_i\) is independent noise \(\epsilon_i \sim \mathcal{N}(0, \sigma_n^2)\), we get a likelihood for a single observation of the form \[ p(y_i \mid \mathbf{x}_i, \mathbf{w}) = \mathcal{N}(y_i \mid \boldsymbol{\phi}(\mathbf{x}_i)^\top \mathbf{w}, \sigma_n^2). \tag{4}\]

Assuming that there is independence across observations, and conditioning on \(\mathbf{w}\), we have that the joint likelihood over \(\mathcal{D}\) becomes \[ p(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) = \prod_{i=1}^{n} \mathcal{N}(y_i \mid \boldsymbol{\phi}(\mathbf{x}_i)^\top \mathbf{w}, \sigma_n^2). \tag{5}\]

Collecting observations into the design matrix \(\Phi \in \mathbb{R}^{n \times M}\) with \(\Phi_{ij} = \phi_j(\mathbf{x}_i)\) (Rasmussen and Williams 2008) (see Appendix 6.3 for the explicit construction), Equation 5 becomes a single multivariate Gaussian rather than a product of univariate Gaussians: \[ p(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) = \mathcal{N}(\mathbf{y} \mid \Phi \mathbf{w}, \sigma_n^2 \mathbf{I}). \tag{6}\]

2.2.2 Posterior over Weights

Applying Bayes’ theorem to this gives the posterior distribution over weights: \[ p(\mathbf{w} \mid \mathbf{X}, \mathbf{y}) = \frac{p(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) p(\mathbf{w})}{p(\mathbf{y} \mid \mathbf{X})}. \tag{7}\]

Because the Gaussian prior is a product of Gaussians, and the likelihood is also Gaussian, the posterior is Gaussian as well (Bishop 2006; Bernardo and Smith 2000). The prior and likelihood are conjugate distributions, so the posterior is in the same family as the prior, this is called conjugacy (Gelman et al. 2025) and is a property that allows for closed-form inference. Evaluating the posterior gives covariance

\[ \Sigma_w = \left(\sigma_n^{-2}\Phi^\top\Phi + \Sigma_p^{-1}\right)^{-1}, \tag{8}\]

and posterior mean \[ \bar{\mathbf{w}} = \sigma_n^{-2} \Sigma_w \Phi^\top \mathbf{y}. \tag{9}\]

The posterior distribution over the weights is therefore \[ p(\mathbf{w} \mid \mathbf{X}, \mathbf{y}) = \mathcal{N}(\mathbf{w} \mid \bar{\mathbf{w}}, \Sigma_w). \tag{10}\]

See ?@sec-posterior-derivation for the full derivation of the posterior mean and covariance.

2.3 Predictive Distribution

This posterior distribution captures both the best estimate of the weights \(\bar{\mathbf{w}}\), and the uncertainty about the weights \(\Sigma_w\). We can use this to make predictions at a new input \(\mathbf{x}_*\) by marginalising over the weight posterior: \[ p(f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}) = \int p(f_* \mid \mathbf{x}_*, \mathbf{w}) p(\mathbf{w} \mid \mathbf{X}, \mathbf{y}) \, d\mathbf{w}, \tag{11}\]

where \(f_* = f(\mathbf{x}_*)\). Since \(f(\mathbf{x}_*) = \boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w}\) is a linear function of \(\mathbf{w}\), the marginal \(p(f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y})\) is also Gaussian (Bishop 2006, chap. 3). Evaluating the integral in closed form gives the predictive mean and variance (see Appendix 6.5 for the full derivation):

\[ \begin{aligned} \text{mean:} \quad & \mathbb{E}[f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}] = \boldsymbol{\phi}(\mathbf{x}_*)^\top \bar{\mathbf{w}}, \\ \text{variance:} \quad & \operatorname{Var}[f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}] = \boldsymbol{\phi}(\mathbf{x}_*)^\top \Sigma_w \boldsymbol{\phi}(\mathbf{x}_*) + \sigma_n^2. \end{aligned} \tag{12}\]

2.4 From Weight Space to Function Space

The predictive distribution in Equation 12 is expressed in terms of the feature map \(\boldsymbol{\phi}\). However, we can see \(\boldsymbol{\phi}\) appears only through inner products with the posterior covariance \(\Sigma_w\), of the form \(\boldsymbol{\phi}(\mathbf{x})^\top \Sigma_p \boldsymbol{\phi}(\mathbf{x}')\). We can define this kernel function (interchangeably called a covariance function) as an inner product in the feature space: (Schölkopf 2002; Rasmussen and Williams 2008) \[ k(\mathbf{x}, \mathbf{x}') = \boldsymbol{\phi}(\mathbf{x})^\top \Sigma_p \boldsymbol{\phi}(\mathbf{x}'), \tag{13}\]

which measures similarity between inputs in the feature space, weighted by the prior covariance \(\Sigma_p\).

With this definition, we can collect all pairwise kernel evaluations over the full training set into the kernel matrix \(K \in \mathbb{R}^{n \times n}\) with \(K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j)\), and the vector of cross-covariances \(\mathbf{k}_* \in \mathbb{R}^n\) with \([\mathbf{k}_*]_i = k(\mathbf{x}_i, \mathbf{x}_*)\). This allows for rewriting the predictive equation entirely in terms of the kernel. This can be done by reparametrizing the posterior covariance \(\Sigma_w = (\sigma_n^{-2}\Phi^\top\Phi + \Sigma_p^{-1})^{-1}\) using the matrix inversion lemma (Rasmussen and Williams 2008, Equation A.9), \[ (A + UCV)^{-1} = A^{-1} - A^{-1}U\bigl(C^{-1} + VA^{-1}U\bigr)^{-1}VA^{-1}, \tag{14}\]

setting \(A = \Sigma_p^{-1}\), \(U = \Phi^\top\), \(C = \sigma_n^{-2}\mathbf{I}\), \(V = \Phi\), which gives the equivalent \(n \times n\) expression: \[ \Sigma_w = \Sigma_p - \Sigma_p\Phi^\top\bigl(\sigma_n^2\mathbf{I} + \Phi\Sigma_p\Phi^\top\bigr)^{-1}\Phi\Sigma_p. \tag{15}\]

In matrix form \(K = \Phi\Sigma_p\Phi^\top\) and \(\mathbf{k}_* = \Phi\Sigma_p\boldsymbol{\phi}(\mathbf{x}_*)\). Substituting Equation 15 into the predictive mean \(\mathbb{E}[f_*] = \sigma_n^{-2}\boldsymbol{\phi}(\mathbf{x}_*)^\top\Sigma_w\Phi^\top\mathbf{y}\): \[ \begin{aligned} \mathbb{E}[f_*] &= \sigma_n^{-2}\boldsymbol{\phi}(\mathbf{x}_*)^\top\Sigma_p\Phi^\top\mathbf{y} - \sigma_n^{-2}\mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}K\mathbf{y} \\ &= \mathbf{k}_*^\top\bigl[\sigma_n^{-2}\mathbf{I} - \sigma_n^{-2}(K+\sigma_n^2\mathbf{I})^{-1}K\bigr]\mathbf{y} \\ &= \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{y}, \end{aligned} \]

where the last step uses \(\sigma_n^{-2}(K+\sigma_n^2\mathbf{I})^{-1}[(K+\sigma_n^2\mathbf{I})-K] = (K+\sigma_n^2\mathbf{I})^{-1}\). Substituting into the variance \(\operatorname{Var}[f_*] = \boldsymbol{\phi}(\mathbf{x}_*)^\top\Sigma_w\boldsymbol{\phi}(\mathbf{x}_*) + \sigma_n^2\): \[ \begin{aligned} \operatorname{Var}[f_*] &= \boldsymbol{\phi}(\mathbf{x}_*)^\top\Sigma_p\boldsymbol{\phi}(\mathbf{x}_*) - \mathbf{k}_*^\top(K+\sigma_n^2\mathbf{I})^{-1}\mathbf{k}_* + \sigma_n^2 \\ &= k(\mathbf{x}_*, \mathbf{x}_*) - \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{k}_* + \sigma_n^2. \end{aligned} \]

The predictive distribution in terms of the kernel is therefore: \[ \begin{aligned} \mathbb{E}[f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}] &= \mathbf{k}_*^\top (K + \sigma_n^2 \mathbf{I})^{-1} \mathbf{y}, \\ \operatorname{Var}[f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}] &= k(\mathbf{x}_*, \mathbf{x}_*) - \mathbf{k}_*^\top (K + \sigma_n^2 \mathbf{I})^{-1} \mathbf{k}_* + \sigma_n^2. \end{aligned} \tag{16}\]

Substituting these into the Gaussian predictive distribution from Equation 11 gives: \[ p(f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}) = \mathcal{N}\!\left(f_* \;\middle|\; \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{y},\; k(\mathbf{x}_*,\mathbf{x}_*) - \mathbf{k}_*^\top(K+\sigma_n^2\mathbf{I})^{-1}\mathbf{k}_* + \sigma_n^2\right). \tag{17}\]

The most important observation here is that \(\boldsymbol{\phi}\) has vanished entirely. The predictions clearly now depend purely on kernel evaluations between data points. We are free to specify \(k\) directly, and we never need to construct an explicit feature map. In particular, if we allow \(M \to \infty\) many basis functions, and we define \(k\) to be the corresponding inner product of this limit, then the model becomes non-parametric. The functions complexity grows with the data rather than being fixed in advance (Williams 1996; D. J. MacKay 1998). Williams (1996) showed that a Bayesian neural network with an infinite number of hidden units and a Gaussian weight prior converges to a GP, formally proving the connection between the weight-space and function-space views.

This is the so called function-space perspective. Instead of reasoning about a weight vector \(\mathbf{w}\), we place a prior directly over functions, characterised entirely by \(k\). The result is a Gaussian process.

3 Gaussian Processes

Formally, a Gaussian process is a collection of random variables, any finite number of which have a joint Gaussian distribution (Rasmussen and Williams 2008). A GP is fully specified by its mean function \(m(\mathbf{x}) = \mathbb{E}[f(\mathbf{x})]\) and covariance function (or kernel) \[ k(\mathbf{x}, \mathbf{x}') = \mathbb{E}[(f(\mathbf{x}) - m(\mathbf{x}))(f(\mathbf{x}') - m(\mathbf{x}'))] = \operatorname{Cov}[f(\mathbf{x}), f(\mathbf{x}')] \tag{18}\]

We write \(f \sim \mathcal{GP}(m, k)\) to denote that \(f\) is a random function drawn from a GP with mean \(m\) and kernel \(k\). The GP provides a prior directly over functions, rather than over a finite parameter vector as in the weight-space view of Section 2.4.

3.1 The GP Prior

Placing a GP prior on \(f\) gives a “prior over functions”. Evaluating \(f\) at any finite collection of inputs \(\mathbf{X} = \{\mathbf{x}_1, \ldots, \mathbf{x}_n\}\) gives a joint Gaussian over the corresponding function values \(\mathbf{f} = [f(\mathbf{x}_1), \ldots, f(\mathbf{x}_n)]^\top\), \[ \mathbf{f} \mid \mathbf{X} \sim \mathcal{N}(\mathbf{m}, K), \tag{19}\]

where \([\mathbf{m}]_i = m(\mathbf{x}_i)\) and \(K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j)\). This property that every finite-dimensional marginal is Gaussian is a defining characteristic of the process (Rasmussen and Williams 2008; Williams and Rasmussen 1995). In regression, it is standard practice to take \(m \equiv 0\): the training targets can be centred by subtracting their mean, and any residual structure is captured by the kernel (D. J. MacKay 1998). However, non-zero mean functions can be useful for encoding strong prior beliefs about the function shape, such as a linear trend or periodicity (Rasmussen and Williams 2008, sec. 2.2).

3.2 Kernels and Covariance Functions

All of the structure of the prior is encoded in the kernel \(k\). The kernel determines how function values co-vary across input space: inputs that are ‘close’, as measured by the kernel \(k\), will have strongly correlated function values, while distant inputs are nearly independent. Kernel hyper-parameters directly control the interpretable properties such as the length-scale (how rapidly the function varies), the output scale (the typical amplitude), and whether the function is stationary or periodic. Figure 1 illustrates this with two common choices: the squared exponential (SE) kernel, which produces infinitely differentiable functions whose roughness is controlled by a length-scale parameter \(\ell\), and the periodic kernel, whose period parameter \(p\) fixes the repetition frequency of the sampled functions.

The SE kernel, which is interchangeably called the radial basis function (RBF) kernel, is defined as \[ k_{\text{SE}}(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \exp\!\left(-\frac{\|\mathbf{x} - \mathbf{x}'\|^2}{2\ell^2}\right), \tag{20}\]

and is the most widely used GP kernel in practice (Rasmussen and Williams 2008). A small \(\ell\) allows the function to vary rapidly over short distances, producing rough wiggly samples, while a large \(\ell\) enforces smoothly varying functions. The periodic kernel, \[ k_{\text{per}}(\mathbf{x}, \mathbf{x}') = \sigma_f^2 \exp\!\left(-\frac{2\sin^2\!\left(\pi|\mathbf{x} - \mathbf{x}'|/p\right)}{\ell^2}\right), \tag{21}\]

explicitly encodes a repeating structure with period \(p\), making it suitable for modelling seasonal or cyclical signals.

Other common kernels include the Matérn family, which has an additional smoothness parameter that controls the differentiability of the sampled functions, and the rational quadratic kernel, which can be seen as a scale mixture of SE kernels and can capture varying length-scales (Rasmussen and Williams 2008, secs. 4.2–4.3).

Kernels can also be combined — sums and products of valid kernels are themselves valid kernels — enabling the construction of structured priors that capture multiple scales or mixed behaviours (Schölkopf 2002).

3.3 Choosing Kernel Hyperparameters

The kernel hyperparameters \(\boldsymbol{\theta}\) (e.g. length-scale \(\ell\), output scale \(\sigma_f^2\), noise variance \(\sigma_n^2\)) are not specified by the GP directly, and must be estimated from data. The standard approach is to maximise the log marginal likelihood (LML) of the observed data under the GP model, which is known as type-II or level-II maximum likelihood or sometimes as empirical Bayes (D. J. C. MacKay 1992; D. J. MacKay 1998; Deisenroth 2010),

\[ \begin{aligned} \log p(\mathbf{y} \mid \mathbf{X}, \boldsymbol{\theta}) &= -\frac{1}{2}\mathbf{y}^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{y} \quad\text{(data fit)} \\ &\quad - \frac{1}{2}\log |K + \sigma_n^2\mathbf{I}| \quad\text{(complexity penalty)} \\ &\quad - \frac{n}{2}\log 2\pi \quad\text{(normalisation constant)}. \end{aligned} \tag{22}\]

This LML has three interpretable terms: the first encourages the model to fit the data well, the second penalises overly complex models that can fit many functions, and the third is a constant that ensures the likelihood is properly normalised. The LML is typically maximised using gradient-based optimisation (e.g. L-BFGS or Adam (Kingma and Ba 2015)), which is tractable for exact GPs since the LML and its gradients can be computed in \(\mathcal{O}(n^3)\) time via Cholesky decomposition of \(K + \sigma_n^2\mathbf{I}\) (Rasmussen and Williams 2008). However, the LML is non-convex and can have multiple local optima, so it is common to perform multiple random restarts to increase the chances of finding a good solution. Additionally, since kernel hyperparameters are typically constrained to be positive, as a negative length-scale or noise variance would not make sense, it is standard practice to optimise them in log-space to ensure positivity and improve numerical stability.

3.4 GP Regression

Given noisy training observations \(\mathbf{y} = \mathbf{f} + \boldsymbol{\epsilon}\) with \(\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \sigma_n^2 \mathbf{I})\) independent of \(\mathbf{f}\), the three blocks of the joint covariance follow directly from the GP prior (see Appendix 6.6 for the full expansion):

\[ \begin{aligned} \operatorname{Cov}[\mathbf{y}, \mathbf{y}] &= \operatorname{Cov}[\mathbf{f} + \boldsymbol{\epsilon}, \mathbf{f} + \boldsymbol{\epsilon}] = K + \sigma_n^2 \mathbf{I}, \\ \operatorname{Cov}[\mathbf{y}, f_*] &= \operatorname{Cov}[\mathbf{f} + \boldsymbol{\epsilon}, f(\mathbf{x}_*)] = \mathbf{k}_*, \\ \operatorname{Cov}[f_*, f_*] &= k(\mathbf{x}_*, \mathbf{x}_*) = k_{**}, \end{aligned} \]

where \([\mathbf{k}_*]_i = k(\mathbf{x}_i, \mathbf{x}_*)\) and \(k_{**} = k(\mathbf{x}_*, \mathbf{x}_*)\). Since \(\mathbf{y}\) and \(f_*\) are jointly Gaussian as linear functions of the GP, the joint distribution over training outputs and test value \(f_* = f(\mathbf{x}_*)\) is: \[ \begin{bmatrix} \mathbf{y} \\ f_* \end{bmatrix} \sim \mathcal{N}\!\left( \mathbf{0},\; \begin{bmatrix} K + \sigma_n^2 \mathbf{I} & \mathbf{k}_* \\ \mathbf{k}_*^\top & k_{**} \end{bmatrix} \right). \tag{23}\]

Conditioning on \(\mathbf{y}\) via the standard Gaussian conditionals (Rasmussen and Williams 2008, Equation 2.19; Bishop 2006, sec. 2.3) gives the posterior predictive distribution: \[ p(y_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}) = \mathcal{N}\!\left(y_* \;\middle|\; \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{y},\; k_{**} - \mathbf{k}_*^\top(K+\sigma_n^2\mathbf{I})^{-1}\mathbf{k}_* + \sigma_n^2\right). \tag{24}\]

This is identical to the weight-space result in Equation 17, but expressed in terms of the kernel rather than the feature map. The posterior mean and covariance are therefore the same as the predictive mean and variance from Equation 16, and we can write the posterior GP as:

\[ \begin{aligned} m_{\text{post}}(\mathbf{x}_*) &= \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{y}, \\ k_{\text{post}}(\mathbf{x}_*, \mathbf{x}_*) &= k_{**} - \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{k}_*. \end{aligned} \tag{25}\]

These expressions have intuitive interpretations: the posterior mean is a linear combination of the observed outputs \(\mathbf{y}\), where the weights are determined by the similarity between the test input and training inputs as measured by the kernel. The posterior variance \(k_{\text{post}}(\mathbf{x}_*, \mathbf{x}_*)\) is the prior variance at \(\mathbf{x}_*\) minus a positive term that captures how much information about \(f(\mathbf{x}_*)\) is contained in the training data. As more data are observed near \(\mathbf{x}_*\), this reduction grows and uncertainty falls. Note that \(\sigma_n^2\) enters both posterior expressions through \((K + \sigma_n^2\mathbf{I})^{-1}\): noisier observations are down-weighted, so the posterior retains more prior uncertainty. The full predictive distribution for a new noisy observation \(y_* = f(\mathbf{x}_*) + \epsilon_*\) adds \(+\sigma_n^2\) to the latent posterior variance, giving Equation 24.

Figure 2 illustrates these properties : the left panel shows three samples from the GP prior, and the right panel shows the posterior after conditioning on observations, where uncertainty collapses near the data and the posterior mean tracks the observations.

3.5 Training a GP

We showed in Section 3.3 that the kernel hyper-parameters \(\boldsymbol{\theta}\) can be estimated by maximising the log marginal likelihood (LML) of the observed data. The LML is a non-convex function of \(\boldsymbol{\theta}\), but its gradients can be computed efficiently using matrix calculus and automatic differentiation, enabling gradient-based optimisation methods such as L-BFGS or Adam (Kingma and Ba 2015) to find good hyperparameter settings. However, computing the LML and its gradients requires an \(\mathcal{O}(n^3)\) Cholesky decomposition of the covariance matrix \(K + \sigma_n^2\mathbf{I}\), which is tractable for moderate \(n\) but becomes prohibitive for large datasets, motivating the development of sparse and approximate inference methods for scaling GPs to larger problems (Snelson and Ghahramani 2006; Titsias 2009).

3.5.1 Gradient of the Log Marginal Likelihood

We have the LML expression from Equation 22: \[\log p(\mathbf{y} \mid \mathbf{X}, \boldsymbol{\theta}) = -\frac{1}{2}\mathbf{y}^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{y} - \frac{1}{2}\log |K + \sigma_n^2\mathbf{I}| - \frac{n}{2}\log 2\pi.\]

The gradient of the LML with respect to a hyperparameter \(\theta_j\) can be derived using the matrix derivative trace formula (Rasmussen and Williams 2008, Equation 5.9), yielding: \[ \frac{\partial \log p(\mathbf{y} \mid \mathbf{X}, \boldsymbol{\theta})}{\partial \theta_j} = \frac{1}{2}\mathbf{y}^\top(K + \sigma_n^2\mathbf{I})^{-1} \frac{\partial (K + \sigma_n^2\mathbf{I})}{\partial \theta_j} (K + \sigma_n^2\mathbf{I})^{-1} \mathbf{y} - \frac{1}{2}\text{tr}\!\left((K + \sigma_n^2\mathbf{I})^{-1} \frac{\partial (K + \sigma_n^2\mathbf{I})}{\partial \theta_j}\right). \]

This expression consists of two terms: the first encourages the model to fit the data well by increasing the LML when the hyperparameter leads to a better fit, while the second penalises overly complex models by decreasing the LML when the hyperparameter increases model complexity. These gradients can be computed efficiently using automatic differentiation libraries, allowing for effective optimisation of the hyperparameters.

In practice, the training loop iterates: (1) evaluate the negative LML via Cholesky factorisation of \(K_\theta + \sigma_n^2\mathbf{I}\); (2) backpropagate to obtain \(\partial \mathcal{L}/\partial \theta_j\) for each hyperparameter; (3) apply an update step (e.g. Adam). Because the LML is non-convex, running multiple random restarts and keeping the solution with the lowest negative LML is common practice. Positive-constrained hyperparameters (\(\ell\), \(\sigma_f^2\), \(\sigma_n^2\)) are parameterised in log-space throughout to ensure positivity and improve the conditioning of the optimisation landscape. Figure 3 illustrates the effect of training: a GP with a poorly initialised length-scale produces an oversmoothed, miscalibrated fit, while the same model after 50 Adam steps accurately recovers the latent function.

The main cost for a prediciton is forming the Cholesky factorisation \(LL^\top = K_{\hat{\boldsymbol{\theta}}} + \sigma_n^2\mathbf{I}\), which is \(\mathcal{O}(n^3)\) and performed once. Once cached, evaluating the predictive mean and variance at a new point requires only two triangular solves and a kernel evaluation, costing \(\mathcal{O}(n)\) per point. Therefore, making prediction at test time once training has been completed is efficient, and the main bottleneck is purely the training phase for large datasets.

The predictive variance at a test point \(\mathbf{x}_*\) decomposes naturally into two parts: \[ \operatorname{Var}[y_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}, \hat{\boldsymbol{\theta}}] = \underbrace{k(\mathbf{x}_*, \mathbf{x}_*) - \mathbf{k}_*^\top(K + \sigma_n^2\mathbf{I})^{-1}\mathbf{k}_*}_{\text{epistemic (reducible)}} + \underbrace{\sigma_n^2}_{\text{aleatoric (irreducible)}}, \tag{26}\]

where the first term is the epistemic uncertainty — reflecting ignorance about the latent function \(f\) — and the second is the aleatoric noise variance (Kendall and Gal 2017). The epistemic component shrinks as training observations accumulate near \(\mathbf{x}_*\), and recovers the full prior variance \(k(\mathbf{x}_*, \mathbf{x}_*)\) only in regions with no data. The aleatoric term \(\sigma_n^2\) is present whenever a noisy observation \(y_* = f(\mathbf{x}_*) + \epsilon_*\) is requested, but absent from the latent predictive distribution over \(f(\mathbf{x}_*)\) itself. This separation is a distinctive strength of the GP framework: the two sources of uncertainty are quantified separately and automatically, without requiring any post-hoc calibration (Rasmussen and Williams 2008; Kendall and Gal 2017).

This is visible in Figure 2: uncertainty collapses near the training observations (low epistemic uncertainty) and inflates in the gaps and at the extrapolation boundaries (high epistemic uncertainty), while the posterior mean threads through the data.

4 Deep Gaussian Processes

The previous section shows how GPs provide closed-form predictions and uncertainty estimates, and are entirely described by the choice of kernel. However, the expressiveness of a single-layer GP is fundamentally constrained by this. A stationary kernel like the squared exponential encodes a fixed idea of smoothness across the entire input space, which may not match real-world data where patterns and smoothness of data may vary in complexity across different regions.

Deep Gaussian Processes (DGPs) address this by composing multiple GP layers hierarchically. Rather than relying on a single kernel, DGPs learn representations at multiple levels of abstraction, much like deep neural networks, while retaining Bayesian uncertainty quantification. This section formally describes the DGP model and shows why exact inference becomes intractable. This leads into the approximate methods of Section 5.

4.1 Definition and Model Formulation

DGPs extend standard GPs by composing multiple GP layers in a hierarchical structure (Damianou and Lawrence 2013). Instead of a single mapping from inputs to outputs, DGPs construct a chain of latent function spaces, each transforming the previous layer.

An \(L\)-layer DGP is defined by a sequence of latent functions \(\{f^{(\ell)}\}_{\ell=1}^{L}\) where each function is drawn from a GP prior conditioned on the output of the previous:

\[ f^{(\ell)} \mid \mathbf{F}^{(\ell-1)} \sim \mathcal{GP}\left(0, k^{(\ell)}(\cdot, \cdot)\right), \quad \ell = 1, \ldots, L, \tag{27}\]

with the convention \(\mathbf{F}^{(0)} = \mathbf{X}\) (the observed inputs). Each layer applies a freshly drawn GP function to the outputs of the previous layer — the first layer warps the raw inputs, the second warps those warped values, and so on. The model is a learned chain of transformations, each inheriting all the uncertainty of the layers before it.

For observed inputs \(\mathbf{X} \in \mathbb{R}^{n \times d_0}\) and outputs \(\mathbf{y} \in \mathbb{R}^n\), the generative model proceeds as:

\[ \begin{aligned} \mathbf{F}^{(1)} &= f^{(1)}(\mathbf{X}), & f^{(1)} &\sim \mathcal{GP}(0, k^{(1)}), \\ \mathbf{F}^{(2)} &= f^{(2)}(\mathbf{F}^{(1)}), & f^{(2)} &\sim \mathcal{GP}(0, k^{(2)}), \\ &\vdots \\ \mathbf{F}^{(L)} &= f^{(L)}(\mathbf{F}^{(L-1)}), & f^{(L)} &\sim \mathcal{GP}(0, k^{(L)}), \\ \mathbf{y} &= \mathbf{F}^{(L)} + \boldsymbol{\epsilon}, & \boldsymbol{\epsilon} &\sim \mathcal{N}(\mathbf{0}, \sigma_n^2 \mathbf{I}), \end{aligned} \tag{28}\]

where \(\mathbf{F}^{(\ell)} \in \mathbb{R}^{n \times d_\ell}\) contains function evaluations at layer \(\ell\) for all \(n\) data points, and \(d_\ell\) is the output dimensionality of layer \(\ell\).

The covariance matrix at layer \(\ell\) is constructed from kernel evaluations at the random outputs of the previous layer:

\[ \left[K^{(\ell)}\right]_{ij} = k^{(\ell)}\left(\mathbf{f}_i^{(\ell-1)}, \mathbf{f}_j^{(\ell-1)}\right), \tag{29}\]

where \(\mathbf{f}_i^{(\ell-1)} \in \mathbb{R}^{d_{\ell-1}}\) is the \(i\)-th row of \(\mathbf{F}^{(\ell-1)}\). When conditioned on the outputs from layer \(\ell-1\), the distribution of \(\mathbf{F}^{(\ell)}\) remains multivariate Gaussian:

\[ p\left(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}\right) = \mathcal{N}\left(\mathbf{F}^{(\ell)} \mid \mathbf{0}, K^{(\ell)}\right). \tag{30}\]

When \(\mathbf{F}^{(\ell-1)}\) is held fixed, this is identical to a standard GP prior — layer \(\ell\) behaves exactly like a regular GP evaluated at those inputs. The difficulty arises only when \(\mathbf{F}^{(\ell-1)}\) is random: the covariance matrix \(K^{(\ell)}\) then becomes a random variable itself, and integrating over it no longer yields a closed form.

The directed graph structure implies that each layer depends only on its immediate predecessor (a Markov property), leading to a factorised joint prior:

\[ p\left(\mathbf{F}^{(1)}, \ldots, \mathbf{F}^{(L)} \mid \mathbf{X}\right) = p\left(\mathbf{F}^{(1)} \mid \mathbf{X}\right) \prod_{\ell=2}^{L} p\left(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}\right). \tag{31}\]

This follows from applying the chain rule and noting that \(\mathbf{F}^{(\ell)} \perp \mathbf{F}^{(1:\ell-2)}, \mathbf{X} \mid \mathbf{F}^{(\ell-1)}\). In plain terms: once you know what layer \(\ell\!-\!1\) output, knowledge of all earlier layers gives no additional information about layer \(\ell\). Practically, this means one can sample through the model one layer at a time, discarding each layer’s outputs once they have been passed forward. The likelihood connects the final layer to observations via \(p(\mathbf{y} \mid \mathbf{F}^{(L)}) = \mathcal{N}(\mathbf{y} \mid \mathbf{F}^{(L)}, \sigma_n^2 \mathbf{I})\).

Equivalently, defining the composed function \(f = f^{(L)} \circ f^{(L-1)} \circ \cdots \circ f^{(1)}\):

\[ \mathbf{y} = f(\mathbf{X}) + \boldsymbol{\epsilon} = f^{(L)}(f^{(L-1)}(\cdots f^{(1)}(\mathbf{X}))) + \boldsymbol{\epsilon}. \tag{32}\]

When layers have output dimension \(d_\ell > 1\), the standard approach uses independent GPs per output dimension:

\[ \mathbf{F}^{(\ell)} = \left[\mathbf{f}^{(\ell,1)}, \ldots, \mathbf{f}^{(\ell,d_\ell)}\right], \quad f^{(\ell,j)} \stackrel{\text{ind}}{\sim} \mathcal{GP}\left(0, k^{(\ell)}\right). \tag{33}\]

This leads to \(\sum_{\ell=1}^{L} n \cdot d_\ell = O(nLd)\) total latent variables.

Figure 4 illustrates the compositional structure of a two-layer DGP. The first layer warps the input, and the second layer operates on the warped space, producing a composed function that would be difficult to represent with a single GP.

The expressiveness of DGPs over standard GPs comes from this composition (Damianou and Lawrence 2013; Dunlop et al. 2018). Even when each layer uses a stationary kernel, the composed function yields a non-stationary process. Consider the covariance of \(g = f^{(2)} \circ f^{(1)}\):

\[ \text{Cov}[g(\mathbf{x}), g(\mathbf{x}')] = \mathbb{E}_{f^{(1)}}\left[k^{(2)}\left(f^{(1)}(\mathbf{x}), f^{(1)}(\mathbf{x}')\right)\right]. \tag{34}\]

This expectation depends on marginal distributions of \(f^{(1)}(\mathbf{x})\) and \(f^{(1)}(\mathbf{x}')\), which change with \(\mathbf{x}, \mathbf{x}'\) through \(k^{(1)}\). The composed covariance is therefore not simply a function of \(\mathbf{x} - \mathbf{x}'\), making the process non-stationary. This input-dependent structure lets DGPs model functions with varying smoothness and lengthscale across input space. To see why this is useful, imagine fitting a signal that is smooth in some regions and rapidly varying in others: a single GP with a fixed lengthscale must compromise, while a DGP can learn to “stretch” the input space in smooth regions and “compress” it in complex regions through \(f^{(1)}\), giving the second layer an effectively adapted coordinate system. 4.2 Intractability of Exact Inference

For standard single-layer GPs, the posterior \(p(f_* \mid \mathbf{X}, \mathbf{y})\) and marginal likelihood \(p(\mathbf{y} \mid \mathbf{X})\) give closed-form expressions due to Gaussian conjugacy (Rasmussen and Williams 2008). In DGPs this is lost because composition of GPs produces a non-Gaussian joint distribution.

The marginal likelihood requires integrating out all latent functions:

\[ p(\mathbf{y} \mid \mathbf{X}) = \int p(\mathbf{y} \mid \mathbf{F}^{(L)}) \prod_{\ell=1}^{L} p(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}) \, d\mathbf{F}^{(1)} \cdots d\mathbf{F}^{(L)}, \tag{35}\]

where \(\mathbf{F}^{(0)} = \mathbf{X}\). This integral has no closed-form solution for \(L \geq 2\) with non-degenerate kernels. The fundamental obstacle is that the covariance matrix \(K^{(\ell)}\) at each layer is a nonlinear function of \(\mathbf{F}^{(\ell-1)}\) — the very variables being integrated over — so the integral cannot be reorganised into the product-of-Gaussians form that makes single-layer GP inference tractable.

To see why, consider a two-layer DGP. The covariance matrix \(K^{(2)}\) depends on \(\mathbf{F}^{(1)}\) through \([K^{(2)}]_{ij} = k^{(2)}(f_i^{(1)}, f_j^{(1)})\). For the squared exponential kernel:

\[ k^{(2)}(h_1, h_2) = \sigma_f^2 \exp\left(-\frac{(h_1 - h_2)^2}{2\ell^2}\right), \tag{36}\]

this is a nonlinear function of the Gaussian random variables \((f_i^{(1)}, f_j^{(1)})\). The integral

\[ \int \mathcal{N}(\mathbf{F}^{(2)} \mid \mathbf{0}, K^{(2)}(\mathbf{F}^{(1)})) \mathcal{N}(\mathbf{F}^{(1)} \mid \mathbf{0}, K^{(1)}) \, d\mathbf{F}^{(1)} \]

is a mixture of Gaussians with continuously varying covariance. Intuitively, for every possible realisation of \(\mathbf{F}^{(1)}\) there is a different Gaussian over \(\mathbf{F}^{(2)}\); marginalising out \(\mathbf{F}^{(1)}\) means averaging together infinitely many Gaussians with different shapes, producing a result that is heavier-tailed and more complex than any individual Gaussian component. No closed form exists for these integrals.

As well as the intractability of the marginal likelihood, the resulting distribution over outputs is non-Gaussian. Consider a two-layer DGP with first-layer outputs \(h_1 = f^{(1)}(x_1)\), \(h_2 = f^{(1)}(x_2)\). From the GP prior:

\[ \begin{bmatrix} h_1 \\ h_2 \end{bmatrix} \sim \mathcal{N}\left(\mathbf{0}, \begin{bmatrix} k^{(1)}_{11} & k^{(1)}_{12} \\ k^{(1)}_{12} & k^{(1)}_{22} \end{bmatrix}\right). \tag{37}\]

Conditioned on \((h_1, h_2)\), the outputs follow:

\[ \begin{bmatrix} y_1 \\ y_2 \end{bmatrix} \Bigg| h_1, h_2 \sim \mathcal{N}\left(\mathbf{0}, \begin{bmatrix} k^{(2)}(h_1, h_1) & k^{(2)}(h_1, h_2) \\ k^{(2)}(h_1, h_2) & k^{(2)}(h_2, h_2) \end{bmatrix}\right). \tag{38}\]

The marginal distribution

\[ p(y_1, y_2) = \int p(y_1, y_2 \mid h_1, h_2) \, p(h_1, h_2) \, dh_1 \, dh_2 \tag{39}\]

is a continuous mixture of Gaussians with varying covariance matrices. Since \(k^{(2)}(h_1, h_2)\) is a nonlinear function of \((h_1, h_2)\), this mixture is not Gaussian.

This can be verified by noting that a Gaussian mixture with continuously varying covariance matrices produces a distribution whose higher moments (e.g., kurtosis) differ from those of any single Gaussian. In particular, the marginal density of \(y_1\) under such a mixture is generally heavier-tailed than any individual Gaussian component (Gelman et al. 2025).

The posterior over all latent functions is:

\[ p(\mathbf{F}^{(1:L)} \mid \mathbf{X}, \mathbf{y}) = \frac{p(\mathbf{y} \mid \mathbf{F}^{(L)}) \prod_{\ell=1}^{L} p(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)})}{p(\mathbf{y} \mid \mathbf{X})}. \tag{40}\]

Since both the numerator (a product of coupled Gaussians) and the denominator (the intractable marginal likelihood) lack closed forms, exact posterior computation is infeasible.

Even numerical integration is impractical. The integration is over \(\sum_{\ell=1}^{L} n d_\ell\) continuous variables, which cannot be factored across layers due to kernel dependencies. This motivates the development of approximate inference methods for DGP learning (Damianou and Lawrence 2013; Salimbeni and Deisenroth 2017).

5 Learning in GP and DGP Models

The previous section showed that DGPs offer richer modelling capacity than standard GPs, but at the cost of tractable inference. This section develops the framework for learning in both settings.

We briefly revisit hyperparameter learning in standard GPs — focusing on how the marginal likelihood arises by integrating out function values — to identify the structural property that is lost in DGPs. We then introduce variational inference for approximating intractable posteriors, build to sparse variational methods that reduce computation from \(O(n^3)\) to \(O(nm^2)\), and finally extend these ideas to DGPs through doubly stochastic variational inference.

5.1 Learning in Standard GPs

As established in Section 3.3, GP hyperparameters \(\boldsymbol{\theta}\) are learned by maximising the log marginal likelihood (LML). It is worth seeing explicitly how this LML arises by integrating out the latent function values \(\mathbf{f}\), since this tractability is precisely what is lost in DGPs.

Starting from the GP prior \(\mathbf{f} \mid \mathbf{X} \sim \mathcal{N}(\mathbf{0}, K_{\boldsymbol{\theta}})\) and likelihood \(\mathbf{y} \mid \mathbf{f} \sim \mathcal{N}(\mathbf{f}, \sigma_n^2 \mathbf{I})\), Gaussian–Gaussian conjugacy (Bernardo and Smith 2000) allows the integral over function values to be computed in closed form: \[ p(\mathbf{y} \mid \mathbf{X}, \boldsymbol{\theta}) = \int p(\mathbf{y} \mid \mathbf{f}) p(\mathbf{f} \mid \mathbf{X}, \boldsymbol{\theta}) \, d\mathbf{f} = \mathcal{N}(\mathbf{y} \mid \mathbf{0}, K_{\boldsymbol{\theta}} + \sigma_n^2 \mathbf{I}), \tag{41}\] giving the LML of Equation 22. The key step is that a Gaussian prior on \(\mathbf{f}\) multiplied by a Gaussian likelihood in \(\mathbf{y}\) integrates analytically: the product of two Gaussians is proportional to a Gaussian, so the \(\mathbf{f}\)-integral collapses to a single multivariate normal with covariance \(K_{\boldsymbol{\theta}} + \sigma_n^2 \mathbf{I}\). This closed-form collapse is precisely what is lost in DGPs, where the covariance depends on random latent variables. Hyperparameters are found via gradient ascent; the gradient with respect to \(\theta_j\) is (Rasmussen and Williams 2008):

\[ \frac{\partial \log p(\mathbf{y})}{\partial \theta_j} = \frac{1}{2}\operatorname{tr}\left((\boldsymbol{\alpha} \boldsymbol{\alpha}^\top - K_y^{-1}) \frac{\partial K_y}{\partial \theta_j}\right), \tag{42}\]

where \(\boldsymbol{\alpha} = K_y^{-1} \mathbf{y}\) and \(K_y = K_{\boldsymbol{\theta}} + \sigma_n^2 \mathbf{I}\). The matrix \(\boldsymbol{\alpha} \boldsymbol{\alpha}^\top - K_y^{-1}\) has a natural interpretation: \(\boldsymbol{\alpha} \boldsymbol{\alpha}^\top\) is a rank-one outer product that captures how the data predicts itself under the current model, while \(K_y^{-1}\) reflects the full model uncertainty; a large positive difference for \(\partial K_y / \partial \theta_j\) indicates that increasing \(\theta_j\) improves the data fit more than it increases model complexity. This follows from the matrix calculus identities \(\frac{\partial}{\partial \theta} \log|K| = \operatorname{tr}(K^{-1} \frac{\partial K}{\partial \theta})\) and \(\frac{\partial K^{-1}}{\partial \theta} = -K^{-1} \frac{\partial K}{\partial \theta} K^{-1}\).

Each gradient step requires \(K_y^{-1}\), computed via Cholesky decomposition at \(O(n^3)\) cost with \(O(n^2)\) storage (Rasmussen and Williams 2008). For small to moderate datasets (\(n \lesssim 10{,}000\)) this is typically feasible and remains the gold standard: the LML gradients are exact, and no approximation is introduced beyond the choice of kernel. For larger datasets the cubic cost becomes prohibitive, motivating the sparse variational approach of the following section.

5.2 Variational Inference

When exact inference is intractable, variational inference gives an approximation framework (Jordan et al. 1999; Blei, Kucukelbir, and McAuliffe 2017). The idea is to approximate the true posterior \(p(\mathbf{z} \mid \mathbf{y})\) with a simpler, and tractable distribution \(q(\mathbf{z})\), which is chosen to minimise the Kullback–Leibler divergence between \(q\) and \(p\):

For latent variables \(\mathbf{z}\) and observations \(\mathbf{y}\), the log marginal likelihood separates as:

\[ \log p(\mathbf{y}) = \mathcal{L}(q) + \operatorname{KL}(q(\mathbf{z}) \| p(\mathbf{z} \mid \mathbf{y})), \tag{43}\]

where the evidence lower bound (ELBO) is:

\[ \mathcal{L}(q) = \mathbb{E}_{q(\mathbf{z})}[\log p(\mathbf{y}, \mathbf{z})] - \mathbb{E}_{q(\mathbf{z})}[\log q(\mathbf{z})] = \mathbb{E}_{q(\mathbf{z})}[\log p(\mathbf{y} \mid \mathbf{z})] - \operatorname{KL}(q(\mathbf{z}) \| p(\mathbf{z})). \tag{44}\]

Since KL divergence is non-negative, \(\mathcal{L}(q) \leq \log p(\mathbf{y})\) with equality when \(q(\mathbf{z}) = p(\mathbf{z} \mid \mathbf{y})\). This is the central insight: rather than computing the intractable posterior directly, we turn the problem into an optimisation — find the \(q\) that maximises the ELBO, which simultaneously tightens the bound and minimises the error of our approximation.

To show Equation 43, start from the definition of KL divergence:

\[ \begin{aligned} \operatorname{KL}(q \| p) &= \mathbb{E}_{q(\mathbf{z})}\left[\log \frac{q(\mathbf{z})}{p(\mathbf{z} \mid \mathbf{y})}\right] = \mathbb{E}_{q(\mathbf{z})}[\log q(\mathbf{z})] - \mathbb{E}_{q(\mathbf{z})}[\log p(\mathbf{z} \mid \mathbf{y})] \\ &= \mathbb{E}_{q(\mathbf{z})}[\log q(\mathbf{z})] - \mathbb{E}_{q(\mathbf{z})}[\log p(\mathbf{y}, \mathbf{z})] + \log p(\mathbf{y}). \end{aligned} \]

Rearranging gives Equation 43. Since \(\operatorname{KL}(q \| p)\) cannot be computed directly (it is intractable), we instead maximise the ELBO, which is equivalent to minimising KL divergence. This replaces an intractable posterior computation with a tractable optimisation problem — the core trade of variational inference.

The second form Equation 44 illuminates the ELBO’s structure. The expected log-likelihood \(\mathbb{E}_{q}[\log p(\mathbf{y} \mid \mathbf{z})]\) encourages \(q\) to concentrate where the data is well-explained, while the KL term \(\operatorname{KL}(q \| p(\mathbf{z}))\) regularises \(q\) toward the prior, preventing overfitting (Bishop 2006). This trade-off mirrors the data-fit versus complexity balance in exact Bayesian inference.

For the models in this dissertation, variational inference serves two purposes: enabling scalability to large datasets, and handling the hierarchical structure of DGPs where function values at each layer cannot be analytically integrated out. The latent variables \(\mathbf{z}\) correspond to function values \(\mathbf{f}\), and the variational distribution is usually chosen to be Gaussian:

\[ q(\mathbf{f}) = \mathcal{N}(\mathbf{f} \mid \mathbf{m}, S), \tag{45}\]

with variational parameters \(\mathbf{m} \in \mathbb{R}^n\) and \(S \in \mathbb{R}^{n \times n}\) (positive definite). This balances expressiveness with computational tractability. The expectations under \(q\) can often be computed analytically for standard likelihood functions.

With this Gaussian choice, the KL term has closed form:

\[ \operatorname{KL}(q(\mathbf{f}) \| p(\mathbf{f})) = \frac{1}{2}\left[\operatorname{tr}(K^{-1}S) + \mathbf{m}^\top K^{-1} \mathbf{m} - n + \log|K| - \log|S|\right], \tag{46}\]

where \(K\) is the prior covariance. Each term has a clear role: \(\mathbf{m}^\top K^{-1} \mathbf{m}\) penalises the variational mean for straying far from zero in units of the prior length-scale; \(\operatorname{tr}(K^{-1}S)\) penalises the variational covariance for being larger than the prior; and \(\log|K| - \log|S|\) is a log-volume ratio that rewards \(q\) for being more concentrated than the prior. Together they ensure \(q\) cannot deviate from \(p(\mathbf{f})\) without paying a KL cost. Optimisation over a full-rank matrix \(S \in \mathbb{R}^{n \times n}\) still involves \(O(n^2)\) parameters, which becomes problematic for large \(n\). The key to resolving this is to restrict the variational family to a lower-dimensional subspace defined by \(m \ll n\) inducing points, as developed in the following section.

5.3 Sparse Variational GPs

The \(O(n^3)\) cost of standard GP inference becomes prohibitive for large datasets. Sparse methods address this by using \(m \ll n\) inducing points that summarise the data, reducing complexity to \(O(nm^2)\) (Quinonero-Candela and Rasmussen 2005; Titsias 2009).

Consider inducing inputs \(\mathbf{Z} = \{\mathbf{z}_j\}_{j=1}^m\) with function values \(\mathbf{u} = f(\mathbf{Z}) \in \mathbb{R}^m\). From the prior, the joint distribution of function values \(\mathbf{f}\) at training inputs and inducing values \(\mathbf{u}\) is:

\[ \begin{bmatrix} \mathbf{f} \\ \mathbf{u} \end{bmatrix} \sim \mathcal{N}\left(\mathbf{0}, \begin{bmatrix} K_{ff} & K_{fu} \\ K_{uf} & K_{uu} \end{bmatrix}\right), \tag{47}\]

where \(K_{ff} = K(\mathbf{X}, \mathbf{X})\), \(K_{fu} = K(\mathbf{X}, \mathbf{Z})\), and \(K_{uu} = K(\mathbf{Z}, \mathbf{Z})\). The cross-covariance \(K_{fu}\) encodes how strongly each training point correlates with each inducing point: if inducing points are placed where the data concentrates, \(K_{fu}\) will be large and the \(m\) inducing values will carry most of the information about the \(n\) function values.

Titsias (2009) introduced a variational framework that treats \(\mathbf{Z}\) as variational parameters rather than fixed pseudo-inputs. The key idea is to use the conditional \(p(\mathbf{f} \mid \mathbf{u})\) from the prior and place a variational distribution on \(\mathbf{u}\):

\[ q(\mathbf{f}, \mathbf{u}) = p(\mathbf{f} \mid \mathbf{u}) q(\mathbf{u}), \tag{48}\]

where \(q(\mathbf{u}) = \mathcal{N}(\mathbf{u} \mid \mathbf{m}, S)\) with variational parameters \(\mathbf{m} \in \mathbb{R}^m\) and \(S \in \mathbb{R}^{m \times m}\). Rather than placing a variational distribution directly on all \(n\) function values \(\mathbf{f}\), we only learn a distribution over the \(m\) inducing values \(\mathbf{u}\) and use the GP conditional \(p(\mathbf{f} \mid \mathbf{u})\) to fill in the rest. This reduces the variational parameter count from \(O(n^2)\) to \(O(m^2)\).

\[ p(\mathbf{f} \mid \mathbf{u}) = \mathcal{N}(\mathbf{f} \mid K_{fu} K_{uu}^{-1} \mathbf{u}, \, K_{ff} - K_{fu} K_{uu}^{-1} K_{uf}). \tag{49}\]

This is the standard GP predictive formula: the conditional mean \(K_{fu}K_{uu}^{-1}\mathbf{u}\) is a weighted combination of inducing values, with weights proportional to how correlated each training point is with each inducing point. The conditional variance \(K_{ff} - K_{fu}K_{uu}^{-1}K_{uf}\) is the prior variance reduced by the information the inducing points provide — it vanishes at the inducing locations themselves.

Marginalising out \(\mathbf{u}\), the variational distribution over \(\mathbf{f}\) is:

\[ q(\mathbf{f}) = \int p(\mathbf{f} \mid \mathbf{u}) q(\mathbf{u}) \, d\mathbf{u} = \mathcal{N}(\mathbf{f} \mid K_{fu} K_{uu}^{-1} \mathbf{m}, \, K_{ff} - K_{fu} K_{uu}^{-1} K_{uf} + K_{fu} K_{uu}^{-1} S K_{uu}^{-1} K_{uf}). \tag{50}\]

Compared to the conditional \(p(\mathbf{f} \mid \mathbf{u} = \mathbf{m})\), the variational posterior \(q(\mathbf{f})\) adds the term \(K_{fu}K_{uu}^{-1}SK_{uu}^{-1}K_{uf}\) to the variance; this restores the uncertainty lost by treating \(\mathbf{u}\) as fixed at \(\mathbf{m}\), so \(q(\mathbf{f})\) correctly reflects that our beliefs about \(\mathbf{u}\) are not perfectly sharp.

The ELBO for this sparse model is (Titsias 2009):

\[ \mathcal{L} = \mathbb{E}_{q(\mathbf{f})}[\log p(\mathbf{y} \mid \mathbf{f})] - \operatorname{KL}(q(\mathbf{u}) \| p(\mathbf{u})). \tag{51}\]

The KL term has closed form:

\[ \operatorname{KL}(q(\mathbf{u}) \| p(\mathbf{u})) = \frac{1}{2}\left[\operatorname{tr}(K_{uu}^{-1}S) + \mathbf{m}^\top K_{uu}^{-1} \mathbf{m} - m + \log|K_{uu}| - \log|S|\right]. \tag{52}\]

For Gaussian likelihoods \(p(\mathbf{y} \mid \mathbf{f}) = \mathcal{N}(\mathbf{y} \mid \mathbf{f}, \sigma_n^2 \mathbf{I})\), the expected log-likelihood can be computed in closed form, yielding a fully analytical ELBO. Optimal parameters satisfy:

\[ \begin{aligned} S^{-1} &= K_{uu}^{-1} + \sigma_n^{-2} K_{uu}^{-1} K_{uf} K_{fu} K_{uu}^{-1}, \\ \mathbf{m} &= \sigma_n^{-2} S K_{uu}^{-1} K_{uf} \mathbf{y}. \end{aligned} \tag{53}\]

With inducing points, predictions at test inputs \(\mathbf{X}_*\) follow:

\[ \begin{aligned} \mathbb{E}[f_*] &= K_{*u} K_{uu}^{-1} \mathbf{m}, \\ \text{Var}[f_*] &= K_{**} - K_{*u} K_{uu}^{-1} (K_{uu} - S) K_{uu}^{-1} K_{u*}. \end{aligned} \tag{54}\]

The computational scaling is \(O(m^3)\) for inverting \(K_{uu}\), \(O(nm^2)\) for matrix products involving \(K_{fu}\), and \(O(m^2)\) storage for variational parameters. Inducing locations \(\mathbf{Z}\) can be jointly optimised with hyperparameters \(\boldsymbol{\theta}\) and variational parameters \((\mathbf{m}, S)\) by gradient ascent on the ELBO.

5.3.1 Stochastic Optimisation via Minibatches

Even at \(O(nm^2)\) per gradient step, iterating over the full dataset each step becomes expensive for large \(n\). For Gaussian likelihoods the expected log-likelihood in Equation 51 decomposes over individual data points: \[ \mathbb{E}_{q(\mathbf{f})}[\log p(\mathbf{y} \mid \mathbf{f})] = \sum_{i=1}^n \mathbb{E}_{q(f_i)}[\log p(y_i \mid f_i)], \tag{55}\] since \(p(\mathbf{y} \mid \mathbf{f}) = \prod_i p(y_i \mid f_i)\) and the marginals \(q(f_i) = \mathcal{N}(f_i \mid [K_{fu}K_{uu}^{-1}\mathbf{m}]_i,\, [K_{ff} - K_{fu}K_{uu}^{-1}(K_{uu}-S)K_{uu}^{-1}K_{uf}]_{ii})\) are available in closed form. The KL term does not depend on the data and can be evaluated once per step. This per-point structure means the ELBO can be estimated unbiasedly from a random minibatch \(\mathcal{B} \subset \{1,\ldots,n\}\) (Hensman, Fusi, and Lawrence 2013): \[ \hat{\mathcal{L}} = \frac{n}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \mathbb{E}_{q(f_i)}[\log p(y_i \mid f_i)] - \operatorname{KL}(q(\mathbf{u}) \| p(\mathbf{u})). \tag{56}\] The factor \(n/|\mathcal{B}|\) re-scales the minibatch sum so that it is an unbiased estimate of the full sum over all \(n\) points: a minibatch of 100 data points still gives a correctly-scaled estimate for a dataset of 100,000. Each step now costs \(O(|\mathcal{B}|m^2 + m^3)\), making gradient-based optimisation tractable even for very large datasets. This minibatch decomposition carries directly into the doubly stochastic DGP estimator Equation 72, which applies the same per-point factorisation across all layers.

This sparse variational framework forms the foundation for scalable DGP inference, with each layer maintaining its own set of inducing points.

5.4 Variational Inference for DGPs

Given the intractability of computing the exact posterior in DGPs, variational inference provides the primary framework for DGP learning (Damianou and Lawrence 2013). The approach extends the sparse variational GP framework by introducing inducing points at each layer.

For an \(L\)-layer DGP, let \(\mathbf{Z}^{(\ell)} \in \mathbb{R}^{m_\ell \times d_{\ell-1}}\) denote inducing inputs at layer \(\ell\), with corresponding inducing outputs \(\mathbf{U}^{(\ell)} = f^{(\ell)}(\mathbf{Z}^{(\ell)}) \in \mathbb{R}^{m_\ell \times d_\ell}\). Following Damianou and Lawrence (2013), the variational distribution factorises across layers:

\[ q(\{\mathbf{F}^{(\ell)}, \mathbf{U}^{(\ell)}\}_{\ell=1}^L) = \prod_{\ell=1}^{L} p(\mathbf{F}^{(\ell)} \mid \mathbf{U}^{(\ell)}, \mathbf{F}^{(\ell-1)}) q(\mathbf{U}^{(\ell)}), \tag{57}\]

where \(q(\mathbf{U}^{(\ell)}) = \mathcal{N}(\mathbf{U}^{(\ell)} \mid \mathbf{M}^{(\ell)}, \mathbf{S}^{(\ell)})\) with variational parameters \(\mathbf{M}^{(\ell)} \in \mathbb{R}^{m_\ell \times d_\ell}\) and covariances \(\mathbf{S}^{(\ell)}\). The factorisation is a key design choice: rather than placing a variational distribution over each layer’s full \(n \times d_\ell\) output matrix, we only learn distributions over the much smaller \(m_\ell \times d_\ell\) inducing outputs at each layer; the per-layer GP conditional \(p(\mathbf{F}^{(\ell)} \mid \mathbf{U}^{(\ell)}, \mathbf{F}^{(\ell-1)})\) then propagates information from inducing values to all training points.

The conditional \(p(\mathbf{F}^{(\ell)} \mid \mathbf{U}^{(\ell)}, \mathbf{F}^{(\ell-1)})\) uses the GP prior structure. For layer \(\ell\) with inputs from the previous layer \(\mathbf{F}^{(\ell-1)}\) and inducing inputs \(\mathbf{Z}^{(\ell)}\):

\[ p(\mathbf{F}^{(\ell)} \mid \mathbf{U}^{(\ell)}, \mathbf{F}^{(\ell-1)}) = \mathcal{N}\left(\mathbf{F}^{(\ell)} \mid A^{(\ell)} \mathbf{U}^{(\ell)}, \, K^{(\ell)}_{ff} - A^{(\ell)} K^{(\ell)}_{uu} A^{(\ell)\top}\right), \tag{58}\]

where \(A^{(\ell)} = K^{(\ell)}_{fu} (K^{(\ell)}_{uu})^{-1}\). Crucially, the covariance matrices \(K^{(\ell)}_{ff}\), \(K^{(\ell)}_{fu}\), and \(K^{(\ell)}_{uu}\) depend on the random inputs \(\mathbf{F}^{(\ell-1)}\), creating dependencies across layers.

The ELBO for DGPs is:

\[ \mathcal{L} = \mathbb{E}_{q(\mathbf{F}^{(1:L)})}[\log p(\mathbf{y} \mid \mathbf{F}^{(L)})] - \sum_{\ell=1}^{L} \operatorname{KL}(q(\mathbf{U}^{(\ell)}) \| p(\mathbf{U}^{(\ell)})). \tag{59}\]

The structure is intuitive: there is one data-fit term (the expected log-likelihood at the final layer) and one KL “regulariser” per layer, penalising each layer’s variational posterior for deviating from its GP prior. The KL terms have closed form since both \(q(\mathbf{U}^{(\ell)})\) and \(p(\mathbf{U}^{(\ell)})\) are Gaussian. However, the expected log-likelihood requires integration over all layer outputs \(\mathbf{F}^{(1:L)}\), which is intractable due to the nested structure.

The expectation in Equation 59 involves:

\[ \mathbb{E}_{q}[\log p(\mathbf{y} \mid \mathbf{F}^{(L)})] = \int \cdots \int \log p(\mathbf{y} \mid \mathbf{F}^{(L)}) \prod_{\ell=1}^{L} q(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}) \, d\mathbf{F}^{(1)} \cdots d\mathbf{F}^{(L)}, \tag{60}\]

where \(q(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)})\) is obtained by integrating out \(\mathbf{U}^{(\ell)}\):

\[ q(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}) = \int p(\mathbf{F}^{(\ell)} \mid \mathbf{U}^{(\ell)}, \mathbf{F}^{(\ell-1)}) q(\mathbf{U}^{(\ell)}) \, d\mathbf{U}^{(\ell)}. \tag{61}\]

This integral is Gaussian:

\[ q(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}) = \mathcal{N}\left(\mathbf{F}^{(\ell)} \mid A^{(\ell)} \mathbf{M}^{(\ell)}, \, K^{(\ell)}_{ff} - A^{(\ell)}(K^{(\ell)}_{uu} - \mathbf{S}^{(\ell)})A^{(\ell)\top}\right). \tag{62}\]

Compared to the GP prior \(p(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}) = \mathcal{N}(\mathbf{0}, K^{(\ell)}_{ff})\), this variational marginal has a non-zero mean (coming from \(\mathbf{M}^{(\ell)}\)) and reduced variance (the term \(A^{(\ell)}(K^{(\ell)}_{uu} - \mathbf{S}^{(\ell)})A^{(\ell)\top}\) subtracts the uncertainty explained by the inducing points, then adds back only what \(\mathbf{S}^{(\ell)}\) says is left). Despite being Gaussian in \(\mathbf{F}^{(\ell)}\) when \(\mathbf{F}^{(\ell-1)}\) is fixed, the overall distribution is non-Gaussian because the covariance matrices \(K^{(\ell)}\) depend nonlinearly on the random \(\mathbf{F}^{(\ell-1)}\).

The nested structure of Equation 60 presents the core challenge: even though each layer’s conditional is Gaussian, the covariance matrices \(K^{(\ell)}\) depend nonlinearly on \(\mathbf{F}^{(\ell-1)}\), precluding closed-form evaluation.

Damianou and Lawrence (2013) addressed this by further approximating the variational distribution. They introduce variational distributions over the intermediate layer outputs:

\[ q(\mathbf{F}^{(\ell)}) = \mathcal{N}(\mathbf{F}^{(\ell)} \mid \boldsymbol{\mu}^{(\ell)}, \boldsymbol{\Sigma}^{(\ell)}), \tag{63}\]

treating \(\{\boldsymbol{\mu}^{(\ell)}, \boldsymbol{\Sigma}^{(\ell)}\}\) as additional variational parameters. This “mean-field” approximation breaks the dependencies between layers but introduces \(O(nLd)\) additional parameters and loses the structure that \(\mathbf{F}^{(\ell)}\) should be generated from \(\mathbf{F}^{(\ell-1)}\) via a GP.

The resulting ELBO becomes:

\[ \mathcal{L}_{\text{MF}} = \mathbb{E}_{q(\mathbf{F}^{(L)})}[\log p(\mathbf{y} \mid \mathbf{F}^{(L)})] - \sum_{\ell=1}^{L} \mathbb{E}_{q(\mathbf{F}^{(\ell-1)})}\left[\operatorname{KL}(q(\mathbf{F}^{(\ell)}) \| p(\mathbf{F}^{(\ell)} \mid \mathbf{F}^{(\ell-1)}))\right]. \tag{64}\]

This approach enabled the original DGP work but suffers from scalability issues (variational parameters grow with \(n\)) and may produce poor approximations due to the mean-field assumption of independence across layers.

5.5 Doubly Stochastic Variational Inference

Salimbeni and Deisenroth (2017) introduced a more elegant approach to DGP inference that avoids the mean-field approximation over layer outputs. The key insight is to use Monte Carlo estimation of the nested expectations while maintaining the exact conditional structure through the GP prior.

The variational distribution retains the form from Equation 57:

\[ q(\{\mathbf{F}^{(\ell)}, \mathbf{U}^{(\ell)}\}) = \prod_{\ell=1}^{L} p(\mathbf{F}^{(\ell)} \mid \mathbf{U}^{(\ell)}, \mathbf{F}^{(\ell-1)}) q(\mathbf{U}^{(\ell)}), \tag{65}\]

but rather than introducing additional variational parameters for \(\mathbf{F}^{(\ell)}\), the method propagates samples through the layers. This respects the hierarchical structure: \(\mathbf{F}^{(\ell)}\) is generated from \(\mathbf{F}^{(\ell-1)}\) via the GP conditional, with uncertainty injected only through the inducing variables \(\mathbf{U}^{(\ell)}\).

The ELBO decomposes over data points:

\[ \mathcal{L} = \sum_{i=1}^{n} \mathbb{E}_{q(f_i^{(L)})}[\log p(y_i \mid f_i^{(L)})] - \sum_{\ell=1}^{L} \operatorname{KL}(q(\mathbf{U}^{(\ell)}) \| p(\mathbf{U}^{(\ell)})). \tag{66}\]

The factorisation follows from \(p(\mathbf{y} \mid \mathbf{F}^{(L)}) = \prod_i p(y_i \mid f_i^{(L)})\). The KL terms have closed form since both \(q(\mathbf{U}^{(\ell)})\) and \(p(\mathbf{U}^{(\ell)})\) are Gaussian (the standard Gaussian KL). The challenge lies in computing \(\mathbb{E}_{q(f_i^{(L)})}[\log p(y_i \mid f_i^{(L)})]\), which requires marginalising over all intermediate layers. The distribution \(q(f_i^{(L)})\) is obtained by integrating:

\[ q(f_i^{(L)}) = \int \cdots \int p(f_i^{(L)} \mid \mathbf{U}^{(L)}, f_i^{(L-1)}) q(\mathbf{U}^{(L)}) \cdots p(f_i^{(1)} \mid \mathbf{U}^{(1)}, \mathbf{x}_i) q(\mathbf{U}^{(1)}) \, d\mathbf{U}^{(1)} \cdots d\mathbf{U}^{(L)}. \tag{67}\]

This nested integral is analytically intractable due to the nonlinear dependence of kernel matrices on previous layer outputs.

The doubly stochastic approach estimates this expectation via Monte Carlo. For data point \(\mathbf{x}_i\), we construct a sample path through all layers. Starting at layer 1, the marginal distribution over \(f_i^{(1)}\) given \(\mathbf{x}_i\) is:

\[ q(f_i^{(1)} \mid \mathbf{x}_i) = \int p(f_i^{(1)} \mid \mathbf{U}^{(1)}, \mathbf{x}_i) q(\mathbf{U}^{(1)}) \, d\mathbf{U}^{(1)}. \tag{68}\]

Since \(p(f_i^{(1)} \mid \mathbf{U}^{(1)}, \mathbf{x}_i) = \mathcal{N}(f_i^{(1)} \mid k_i^{(1)\top} (K_{uu}^{(1)})^{-1} \mathbf{U}^{(1)}, \, k_{ii}^{(1)} - k_i^{(1)\top} (K_{uu}^{(1)})^{-1} k_i^{(1)})\) and \(q(\mathbf{U}^{(1)}) = \mathcal{N}(\mathbf{M}^{(1)}, \mathbf{S}^{(1)})\), integrating out \(\mathbf{U}^{(1)}\) yields:

\[ \begin{aligned} \mu_i^{(1)} &= k_i^{(1)\top} (K_{uu}^{(1)})^{-1} \mathbf{M}^{(1)}, \\ \sigma_i^{(1)2} &= k_{ii}^{(1)} - k_i^{(1)\top} (K_{uu}^{(1)})^{-1} (K_{uu}^{(1)} - \mathbf{S}^{(1)}) (K_{uu}^{(1)})^{-1} k_i^{(1)}, \end{aligned} \tag{69}\]

where \(k_i^{(1)} = k^{(1)}(\mathbf{x}_i, \mathbf{Z}^{(1)}) \in \mathbb{R}^{m_1}\) and \(k_{ii}^{(1)} = k^{(1)}(\mathbf{x}_i, \mathbf{x}_i)\). The mean \(\mu_i^{(1)}\) is the posterior GP mean at \(\mathbf{x}_i\): a weighted sum of inducing values \(\mathbf{M}^{(1)}\), weighted by how correlated \(\mathbf{x}_i\) is with each inducing point. The variance \(\sigma_i^{(1)2}\) is the prior variance \(k_{ii}^{(1)}\) minus the information contributed by the inducing points, plus additional uncertainty from \(\mathbf{S}^{(1)}\) reflecting that our beliefs about \(\mathbf{U}^{(1)}\) are not perfectly sharp.

Sampling \(f_i^{(1)} \sim \mathcal{N}(\mu_i^{(1)}, \sigma_i^{(1)2})\) gives a realisation of the first layer output. For subsequent layers \(\ell = 2, \ldots, L\), we condition on the sampled value from the previous layer. The distribution at layer \(\ell\) given sampled \(f_i^{(\ell-1)}\) is:

\[ q(f_i^{(\ell)} \mid f_i^{(\ell-1)}) = \int p(f_i^{(\ell)} \mid \mathbf{U}^{(\ell)}, f_i^{(\ell-1)}) q(\mathbf{U}^{(\ell)}) \, d\mathbf{U}^{(\ell)}, \tag{70}\]

with mean and variance:

\[ \begin{aligned} \mu_i^{(\ell)} &= k^{(\ell)}(f_i^{(\ell-1)}, \mathbf{Z}^{(\ell)})^\top (K_{uu}^{(\ell)})^{-1} \mathbf{M}^{(\ell)}, \\ \sigma_i^{(\ell)2} &= k^{(\ell)}(f_i^{(\ell-1)}, f_i^{(\ell-1)}) - k^{(\ell)}(f_i^{(\ell-1)}, \mathbf{Z}^{(\ell)})^\top (K_{uu}^{(\ell)})^{-1} (K_{uu}^{(\ell)} - \mathbf{S}^{(\ell)}) (K_{uu}^{(\ell)})^{-1} k^{(\ell)}(\mathbf{Z}^{(\ell)}, f_i^{(\ell-1)}). \end{aligned} \tag{71}\]

The same formula applies as at layer 1, except that the input is now the sampled value \(f_i^{(\ell-1)}\) from the previous layer rather than the fixed training input \(\mathbf{x}_i\). This is how uncertainty propagates: each layer outputs a Gaussian whose mean and variance depend on a random draw from the layer below, so uncertainty compounds as samples pass through the hierarchy.

The kernel evaluations now depend on the random variable \(f_i^{(\ell-1)}\) from the previous layer, creating the propagation of uncertainty.

After sampling through all \(L\) layers, we obtain \(f_i^{(L)}\) and evaluate \(\log p(y_i \mid f_i^{(L)})\). With \(S\) independent sample paths, the Monte Carlo estimate of the ELBO is:

\[ \hat{\mathcal{L}} = \frac{n}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \frac{1}{S} \sum_{s=1}^{S} \log p(y_i \mid f_i^{(L,s)}) - \sum_{\ell=1}^{L} \operatorname{KL}(q(\mathbf{U}^{(\ell)}) \| p(\mathbf{U}^{(\ell)})), \tag{72}\]

where \(\mathcal{B} \subset \{1, \ldots, n\}\) is a minibatch and \(f_i^{(L,s)}\) denotes the \(s\)-th sample at the final layer for point \(i\). The factor \(n/|\mathcal{B}|\) corrects for minibatch subsampling, ensuring the estimate remains unbiased.

The term “doubly stochastic” refers to two sources of randomness: minibatch subsampling (stochasticity over data) and Monte Carlo sampling through layers (stochasticity over latent functions). Both maintain unbiasedness of gradient estimates, which is crucial for stochastic optimisation convergence. In practice the two sources of noise act independently: increasing the minibatch size \(|\mathcal{B}|\) reduces noise from data sampling, while increasing the sample count \(S\) reduces noise from layer propagation.

Gradient computation requires differentiating through the sampling operations. The reparametrisation trick (Kingma and Welling 2014) makes this tractable: instead of sampling \(f \sim \mathcal{N}(\mu, \sigma^2)\) directly, we write \(f = \mu + \sigma\epsilon\) with \(\epsilon \sim \mathcal{N}(0,1)\), so that gradients with respect to \(\mu\) and \(\sigma\) flow through the deterministic transformation while the stochastic node \(\epsilon\) carries no parameters. In effect, the randomness is “pushed outside” the computation graph, so automatic differentiation can treat \(\mu\) and \(\sigma\) as ordinary differentiable variables.

Computational cost per iteration is \(O(|\mathcal{B}| m^2 L S)\) for forward propagation of \(S\) samples through \(L\) layers, plus \(O(m^3 L)\) for the KL terms. Crucially, this is independent of \(n\), enabling scalability to large datasets. Empirically, a single sample (\(S=1\)) often suffices when \(|\mathcal{B}|\) is large, as averaging over many data points provides natural variance reduction.

6 Deep Gaussian Processes for Financial Risk Modeling

Gaussian processes are well-established Bayesian non-parametric models for regression and classification, and GP-based recurrent extensions have also been used for time-series modelling (Mattos et al. 2016). Deep Gaussian processes extend this framework by composing multiple GP layers, giving a more expressive probabilistic model while retaining an explicit treatment of predictive uncertainty (Damianou and Lawrence 2013; Salimbeni and Deisenroth 2017).

In finance, GP-based methods have been applied to credit-risk and credit-rating problems (Mahajan et al. 2022; Huang 2011), volatility forecasting (Munoz-Gonzalez, Lazaro-Gredilla, and Figueiras-Vidal 2014), algorithmic trading strategy identification (Yang et al. 2015), and market-risk approximation for trading portfolios (Lehdili, Oswald, and Nguyen 2025). Basel III and the wider Basel Framework make banks’ capital requirements explicitly risk-sensitive, so reliable estimates of probability of default (PD) and other loss-related quantities are important for both regulatory compliance and internal risk management (“Basel III: A Global Regulatory Framework for More Resilient Banks and Banking Systems” 2011). Against that background, comparing GPs and DGPs for credit-risk prediction is well motivated. At the same time, the finance literature cited above is still dominated by standard GP variants, with direct DGP applications appearing much less common. Likely due to the regulatory issues around using black-box models in finance, and the computational challenges of training DGPs at scale, there is a gap in the literature around the practical performance of DGPs for financial risk modelling. This section therefore compares GPs and DGPs with standard machine learning baselines on financial datasets, focusing on both predictive performance and the quality of uncertainty quantification, while also considering computational cost and interpretability.

6.1 Credit Card Probability of Default

The first empirical study addresses 2 question: can GP and DGP classifiers serve as credible probability-of-default (PD) models under realistic credit-risk conditions, and does the additional expressiveness of DGPs translate into superior performance relative to single-layer GPs and classical machine learning baselines for this data?

The benchmark used is the UCI default of credit card clients dataset (Yeh and Lien 2009), comprising 30,000 observations and 23 predictor variables: credit limit, demographics, six months of repayment-status history, and corresponding billing and repayment amounts from April–September 2005. The target indicates default on the October 2005 payment. This benchmark is well-established in the credit-risk literature (Thomas 2000; Huang 2011; Mahajan et al. 2022) and presents two simultaneous evaluation criteria: ranking quality discrimination ability (does the model correctly order clients by default risk?) and probability calibration (are the predicted default probabilities credible estimates of the observed default frequencies?). Under the Basel IRB Advanced Approach, both criteria carry legal and capital weight (“Basel III: A Global Regulatory Framework for More Resilient Banks and Banking Systems” 2011; European Banking Authority 2017).

6.1.1 Data Preparation and Experimental Design

Undocumented education and marriage codes were collapsed into an “other” category; skewed monetary variables (bill amounts and repayment amounts) were log-transformed to reduce leverage from extreme values; categorical variables were one-hot encoded with drop_first=True; and all continuous predictors were standardised to zero mean and unit variance fit on the training split only to prevent leakage (see Section 6.7.2 for the implementation). The full 30,000-observation dataset was first split into a fixed held-out test set of 6,000 observations (20%), due to large class imbalance this was stratified by the target variable to ensure equal default rates across train and test. The remaining 24,000 observations are used for training and validation subsets. This ensures all models across sizes are evaluated on the same test set, giving a fair comparison across training dataset sizes.

We evaluated three size tiers to study the effect of data quantity on performance:

  • Small: (\(N_{\text{dev}} = 500\)): 425 training, 75 validation observations.
  • Medium: (\(N_{\text{dev}} = 5{,}000\)): 4,250 training, 750 validation observations.
  • Large: (\(N_{\text{dev}} = 24{,}000\)): 20,400 training, 3,600 validation observations (full development set).

The validation split (15% of dev) is used only for XGBoost early stopping and all other models train on the full train+validation set after hyperparameter selection following the convention for small-data GP experiments in Hensman, Fusi, and Lawrence (2013). The test set default rate is 22.1% across all tiers.

6.1.2 Model Set and Training Configuration

The model set comprises three classical tabular baselines and three GP-family models:

  • Logistic Regression with class_weight="balanced" — the standard imbalance-aware linear baseline.
  • Random Forest with 500 trees and class_weight="balanced_subsample" — a non-linear ensemble baseline with built-in imbalance handling.
  • XGBoost with scale_pos_weight — a gradient-boosted tree ensemble with early stopping tuned on the validation set, then refitted on train+validation at the best iteration count.
  • SVGP — sparse variational GP with 512 inducing points, 150 training epochs, and variational ELBO (Hensman, Fusi, and Lawrence 2013).
  • DSVGP-2L — two-layer deep sparse variational GP with doubly stochastic inference (Salimbeni and Deisenroth 2017), 128 inducing points per layer, hidden dimension 5.
  • DSVGP-3L — three-layer variant of the above.

6.1.3 Results at Full Scale (Large Tier)

6.1.3.1 Discriminative Performance

On threshold-independent ranking metrics, the six models form three tiers. XGBoost leads at ROC-AUC = 0.779 and average precision = 0.553, consistent with its strong performance on structured tabular data. The GP family follows closely: DSVGP-2L = 0.778, DSVGP-3L = 0.777, SVGP = 0.776 — a gap of \(\Delta = 0.001\)–\(0.003\). Bootstrap 95% CIs span approximately \(\pm 0.015\), and the intervals for XGBoost, DSVGP-2L, DSVGP-3L, and SVGP overlap completely: these four models are statistically indistinguishable on discrimination (Section 6.11). The point-estimate ordering within this group carries no weight. Random forest (0.769) and logistic regression (0.739) however do trail significantly. Logistic regression was worse, likely due to its inability to capture the non-linear interactions between repayment-status history and monetary variables that score highly on feature importance.

At each model’s F1-optimal threshold, the six models converge dramatically: SVGP achieves F1 = 0.547 at \(t^* = 0.30\), DSVGP-2L = 0.546 at \(t^* = 0.29\), XGBoost = 0.544 at \(t^* = 0.55\), DSVGP-3L = 0.545 at \(t^* = 0.32\), Random Forest = 0.542 at \(t^* = 0.47\), and Logistic Regression = 0.519 at \(t^* = 0.58\). The GP models’ lower optimal thresholds (0.29–0.32 versus 0.47–0.58 for classical models) reflect their characteristic narrower score distribution: the sigmoid-linked posterior concentrates predictions in a narrower probability band, requiring a lower cutoff to achieve the same sensitivity. This is not a deficiency — it is a direct consequence of the principled uncertainty quantification that also produces superior calibration.

6.1.3.2 Probability Calibration

The principal advantage of GP and DGP classifiers on this dataset is probability calibration. SVGP achieves ECE = 0.015 and Brier = 0.136; DSVGP-3L: ECE = 0.016, Brier = 0.136; DSVGP-2L: ECE = 0.017, Brier = 0.135. Classical baselines are substantially worse: logistic regression ECE = 0.225, XGBoost ECE = 0.196, random forest ECE = 0.087. The GP models achieve approximately 12\(\times\) lower ECE than XGBoost and 13\(\times\) lower than logistic regression.

This pattern aligns with Niculescu-Mizil and Caruana (2005), who show empirically that gradient-boosted ensembles are systematically overconfident while sigmoid-linked probabilistic models tend toward well-calibrated posteriors. The GP models are well-calibrated natively because the variational ELBO penalises over-confident posteriors and the Bernoulli-sigmoid link ensures appropriate uncertainty near the decision boundary (Hensman, Fusi, and Lawrence 2013).

Random forest occupies an intermediate position (ECE = 0.087): its bagging mechanism provides some calibration smoothing, but the frequency-based probability estimates from leaf nodes are still systematically biased relative to the Bayesian posterior of the GP family (Niculescu-Mizil and Caruana 2005).

Under the Basel IRB Advanced Approach, PD estimates must track observed default rates across rating grades (European Banking Authority 2017; “Basel III: A Global Regulatory Framework for More Resilient Banks and Banking Systems” 2011). A raw ECE of 0.196 (XGBoost) implies average deviations of nearly 20 percentage points per quantile bin — a level that would fail a standard supervisory calibration review and distort IFRS 9 expected credit loss provisions (International Accounting Standards Board 2014). GP models satisfy this standard natively; classical models would require a post-hoc calibration stage (Platt scaling (Platt 1999) or isotonic regression (Zadrozny and Elkan 2002)) that adds to both the data budget and the validation surface area under model risk frameworks such as SR 11-7 (Board of Governors of the Federal Reserve System 2011). However, introducing a post-hoc calibration layer raises its own regulatory concerns: the calibration mapping is itself a model component that must be validated, monitored, and governed. In high-stakes applications such as IRB PD estimation, each additional model component increases the total validation burden and creates a potential point of failure during model monitoring. The GP’s native calibration avoids this additional complexity entirely.

6.1.4 Scaling Behaviour Across Training Set Sizes

ROC and precision-recall curves and reliability diagrams at each training tier are provided in Section 6.8.

6.1.4.1 Discriminative Scaling

All models benefit from additional training data, but the magnitude and pattern of improvement differ across families.

Classical models. XGBoost shows the strongest scaling response: ROC-AUC improves from 0.734 (small) to 0.779 (large), a gain of +0.045. This is characteristic of gradient-boosted ensembles’ well-documented capacity to exploit large training sets through deeper tree structures and more refined split boundaries. Random forest improves more modestly (+0.023), and logistic regression shows the weakest response (+0.023), as a linear model that has already captured most of its achievable signal from the dominant repayment-status features at small scale.

GP models. SVGP improves from 0.744 to 0.776 (+0.032), while DSVGP-2L shows a comparable trajectory from 0.741 to 0.778 (+0.037). Both GP variants converge toward XGBoost at large scale: at the medium tier, DSVGP-2L (0.768) and SVGP (0.766) already match or exceed random forest (0.760), and the gap to XGBoost (0.758) has closed to within 0.01.

DSVGP-3L failure at small scale. The three-layer DGP achieves only ROC-AUC = 0.529 — effectively random — when trained on 425 observations. This is a clear instance of the pathological behaviour identified by Duvenaud et al. (2014), whereby deeper GP architectures suffer from vanishing kernel gradients and poor optimisation in the low-data regime. With only 425 training points and three layers of inducing-point variational parameters to optimise, the posterior collapses to a near-constant prediction. At medium scale (4,250 observations), DSVGP-3L recovers fully to 0.765, and at large scale it matches DSVGP-2L at 0.777. This demonstrates that the additional expressive capacity of deeper architectures requires sufficient data volume to be realised — a practical constraint that favours DSVGP-2L as the default configuration for credit-risk applications where training data may be limited.

6.1.4.2 Calibration Scaling

The calibration behaviour across tiers reveals a qualitatively different pattern from discrimination.

GP models maintain excellent calibration at all scales. SVGP achieves ECE = 0.029 at small scale, improving to 0.011 at medium and settling at 0.015 at large. DSVGP-2L follows a similar trajectory (0.025 → 0.019 → 0.017). The key observation is that GP calibration quality is excellent from 425 training observations onward: an ECE of 0.025–0.029 represents average per-bin probability deviations of 2.5–2.9 percentage points, well within the tolerance of a supervisory PD calibration review (European Banking Authority 2017).

Classical models are miscalibrated at all scales and do not improve with more data. Logistic regression ECE is 0.205 at small scale and 0.225 at large — essentially constant. XGBoost ECE actually worsens from 0.164 (small) to 0.196 (large), as a more confidently fitted model produces more extreme probability estimates without a mechanism to pull them back toward calibration. Random forest is better calibrated than the other classicals (ECE \(\approx 0.09\) at all scales) due to the averaging effect of bagging, but still represents 5–6\(\times\) worse calibration than the GP family.

This scaling pattern is a structural consequence of model architecture: GP models derive calibration from the Bayesian posterior’s principled treatment of uncertainty, which operates regardless of sample size (Bernardo and Smith 2000). Classical models derive their probability estimates from point-estimate decision functions (logit, tree leaf frequencies, boosted scores) that lack an inherent uncertainty calibration mechanism (Niculescu-Mizil and Caruana 2005).

6.1.5 Computational Profile

DSVGP-3L is the most expensive model at 582.8 seconds — nearly 3.5\(\times\) the cost of the two-layer variant — yet yields no material improvement over DSVGP-2L on any metric at large scale (ROC-AUC: 0.777 vs 0.778; ECE: 0.016 vs 0.017). This is consistent with Duvenaud et al. (2014), who demonstrate that additional GP layers suppress rather than enhance flexibility on smooth finite datasets. DSVGP-2L is consequently the more defensible configuration: it achieves near-best discrimination, excellent calibration, and less than one-third the training cost of the three-layer variant.

For deployment contexts, the GP training time penalty (168 s for DSVGP-2L vs 0.58 s for XGBoost at large scale — a \(290\times\) factor) is a batch training cost incurred once per model refresh cycle. In credit-risk production environments where models are retrained monthly or quarterly, this is operationally negligible. Inference time for a single prediction is comparable across model families.

6.1.6 Discussion

Discriminative performance. At full scale, GP and DGP classifiers are competitive with gradient-boosted trees on all threshold-independent metrics, with ROC-AUC gaps of \(\Delta \leq 0.003\) — smaller than the \(\pm 0.015\) bootstrap CI width — meaning XGBoost and the GP family are statistically tied on discrimination (Section 6.11). At each model’s F1-optimal threshold, the GP family achieves the highest F1: SVGP = 0.547 versus XGBoost’s 0.544, eliminating the artefactual gap that appears when all models are evaluated at a fixed \(t = 0.5\) cutoff. The GP models’ lower optimal thresholds (0.29–0.32) versus classical models (0.47–0.58) reflect their narrower posterior score distributions — an expected consequence of principled Bayesian uncertainty quantification, not a modelling deficiency. In practice, this means that any deployment of these models must include a threshold selection step, ideally calibrated to the specific cost structure of the application (e.g., the relative cost of false positives vs false negatives in credit decisioning). Due to GPs much more accurate probability estimates, this threshold selection can be done purely off a chosen probability cutoff (e.g., 0.5) without needing to adjust for the model’s score distribution, which is a practical, and interpretability, advantage over classical baselines which would require a more complex threshold selection process or post-hoc calibration to achieve the same effect.

Probability calibration. The structural advantage of GP and DGP models on this task is native probability calibration. At large scale, the GP family achieves ECE = 0.015–0.017 compared to 0.087–0.225 for classical baselines — a 5–13\(\times\) improvement requiring no additional calibration step, calibration data holdout, or post-hoc model component. This advantage is maintained across all training set sizes: even at small scale (425 training observations), GP models achieve ECE = 0.025–0.029, far superior to any classical baseline. For regulatory PD applications requiring credible default probability estimates under Basel IRB (European Banking Authority 2017) or IFRS 9 (International Accounting Standards Board 2014), this native calibration is a material operational advantage that eliminates both the calibration data tax and the additional validation surface imposed by post-hoc calibration methods (Platt 1999; Zadrozny and Elkan 2002).

Practical implications. These results carry both positive and cautionary messages for credit-risk practitioners. On the positive side, GP models deliver near-identical discriminative power to XGBoost while offering dramatically better calibration — the property that matters most for regulatory PD estimation. A bank adopting a GP-based PD model could expect regulatory capital calculations and IFRS 9 provisions that more accurately reflect true portfolio risk, reducing both the risk of supervisory challenge and the capital drag from over-conservative PD estimates. On the cautionary side, the training time premium (~290\(\times\)) and the need for threshold optimisation add operational complexity. For portfolios where calibration quality is not subject to direct regulatory scrutiny (e.g., marketing scorecards), the simpler XGBoost pipeline may be preferable.

Architecture depth. Adding a third GP layer (DSVGP-3L) offers no benefit over DSVGP-2L at medium or large scale on any metric, while incurring approximately \(3.5\times\) the training cost. At small scale, the three-layer architecture fails catastrophically (ROC-AUC = 0.529), confirming the practical relevance of the pathological deep GP behaviours identified by Duvenaud et al. (2014). DSVGP-2L is the dominant configuration across all training regimes for this dataset.

GP vs DGP. The marginal improvement from SVGP to DSVGP-2L is +0.002 ROC-AUC at large scale — not statistically significant given the \(\pm 0.015\) CI width (Section 6.11), and below any threshold of practical relevance. This gap is modest relative to the 17% increase in training time (168 s vs 144 s). On calibration, both architectures achieve comparable ECE (\(\leq 0.02\)). For this dataset, the single-layer SVGP provides approximately equivalent discriminative and calibration performance to the deep architecture at lower computational and optimisation risk. The additional compositional flexibility of DGPs (Damianou and Lawrence 2013) does not yield materially different representations on this smooth, moderate-dimensional credit dataset.

6.2 Freddie Mac Mortgage Probability of Default

The second empirical study applies the same model set to a structurally different credit problem: residential mortgage probability of default. The data are drawn from the Freddie Mac Single-Family Loan-Level Dataset, a publicly available supervisory-quality source covering origination characteristics and monthly loan performance for conforming mortgages purchased or guaranteed by Freddie Mac. This dataset is widely used in mortgage credit-risk research and regulatory stress-testing (“Basel III: A Global Regulatory Framework for More Resilient Banks and Banking Systems” 2011) because it provides the granularity needed for loan-level PD modelling: origination credit score (FICO), combined loan-to-value (CLTV), debt-to-income ratio (DTI), original unpaid principal balance (UPB), coupon rate, loan purpose, property type, occupancy status, geographic region, and origination vintage.

The mortgage setting differs from the credit-card benchmark of Section 6.1 in three material respects. First, the default rate is far lower: approximately 1.7% versus 22.1%, making this a heavily imbalanced classification problem where the positive class is rare and most conventional threshold-dependent metrics become uninformative at any fixed cutoff. Second, the feature space includes structured domain covariates (FICO, LTV, DTI, vintage era, refinancing incentive) whose interactions are well-studied in the mortgage finance literature and carry direct economic interpretation. Third, the regulatory context is more demanding: mortgage PD models feed directly into Basel IRB capital calculations, IFRS 9 expected credit loss provisions, and CCAR/DFAST stress-testing submissions, where probability calibration is subject to direct supervisory scrutiny (European Banking Authority 2017; International Accounting Standards Board 2014; Board of Governors of the Federal Reserve System 2011).

6.2.1 Data Preparation and Experimental Design

Origination and monthly performance files were loaded for all available quarters, retaining only those with at least 24 months of seasoning — the standard observation window for through-the-cycle PD estimation under Basel III (“Basel III: A Global Regulatory Framework for More Resilient Banks and Banking Systems” 2011). A loan is labelled as defaulted if it reached 90+ days past due or experienced a credit-event liquidation (foreclosure, short sale, or related disposition) within 24 months of origination. This definition aligns with the Basel IRB default definition and is standard across the mortgage PD literature.

From the pool of qualifying origination records, a stratified subsample of 30,000 loans was drawn using proportional allocation across three stratification variables: vintage era (pre-crisis, crisis, post-crisis, COVID), refinancing incentive bucket (in-the-money, at-the-money, out-of-the-money based on rate spread relative to cohort median), and US Census geographic region (Northeast, Midwest, South, West). This stratified sampling preserves the portfolio-level distributional structure that drives mortgage default heterogeneity while reducing the dataset to a computationally manageable size.

Pre-processing followed the same conventions as Section 6.1. Categorical variables — loan purpose, property type, occupancy status, origination channel, first-time buyer flag, vintage era, refinancing bucket, LTV bucket, and geographic region — were one-hot encoded with drop_first=True to avoid the dummy-variable trap. Numeric covariates (credit score, original LTV, DTI, coupon rate, UPB, mortgage insurance percentage, rate spread, number of borrowers, number of units, original term, and origination year) were log-transformed where appropriate and standardised to zero mean and unit variance. The scaler was fit on training data only to prevent leakage.

The 30,000-loan sample was split into a fixed held-out test set of 6,000 observations (20%), stratified by the target. The remaining 24,000 observations form the development pool. Three training-set size tiers were evaluated:

  • Small (\(N_{\text{dev}} = 500\)): 425 training, 75 validation observations.
  • Medium (\(N_{\text{dev}} = 5{,}000\)): 4,250 training, 750 validation observations.
  • Large (\(N_{\text{dev}} = 24{,}000\)): 20,400 training, 3,600 validation observations (full development set).

The test set default rate is 1.73% across all tiers — approximately one-thirteenth the rate observed in the credit-card benchmark. This extreme class imbalance means that a naive majority-class classifier achieves 98.3% accuracy, rendering accuracy-based evaluation meaningless. The analysis therefore focuses on ROC-AUC for discrimination and ECE for calibration.

6.2.2 Model Set and Training Configuration

The model set is identical to Section 6.1.2: logistic regression (class_weight="balanced"), random forest (500 trees, class_weight="balanced_subsample"), XGBoost (scale_pos_weight, early stopping on validation), SVGP (512 inducing points, 150 epochs), DSVGP-2L (128 inducing points per layer, hidden dimension 5), and DSVGP-3L.

The low default rate creates a specific challenge for threshold selection. At 1.73% base rate, a well-calibrated model should output probabilities near 0.017 for the majority of observations. The sigmoid-linked GP posterior naturally produces such concentrated estimates, meaning the predicted probability mass lies far below the conventional \(0.5\) threshold. At \(t = 0.5\), F1 is exactly zero for random forest, SVGP, DSVGP-2L, and DSVGP-3L across all tiers — these models correctly assign very low default probabilities to the overwhelmingly non-default majority, resulting in zero positive predictions at that cutoff. This makes using a fixed \(0.5\) threshold absurd for this dataset; even well-calibrated models that perfectly track the true 1.7% default rate would appear to “fail” at this cutoff. All threshold-dependent metrics below are therefore reported at each model’s F1-optimal threshold (\(t^*\)), which ranges from 0.02 to 0.81 depending on model and tier. Even at optimal thresholds, the best achievable F1 is approximately 0.15, reflecting the fundamental difficulty of achieving high precision and recall simultaneously at 1.73% prevalence. ROC-AUC, which evaluates the full ranking over all thresholds, is the appropriate primary metric. Statistical uncertainty in all metrics is quantified via 2,000-resample bootstrap confidence intervals (percentile method); see Section 6.11.

6.2.3 Results at Full Scale (Large Tier)

The most striking feature of Table 5 is the enormous variation in optimal thresholds: GP models require \(t^* \in [0.07, 0.09]\) while logistic regression requires \(t^* = 0.81\) and XGBoost requires \(t^* = 0.59\). This divergence arises because well-calibrated models (the GP family) produce predicted probabilities clustered near the true base rate of 1.7%, while miscalibrated models (logistic regression, XGBoost) produce inflated probability estimates that must be thresholded much higher to separate defaults from non-defaults.

6.2.3.1 Discriminative Performance

On the mortgage dataset, point estimates place DSVGP-3L first at ROC-AUC = 0.823, followed by DSVGP-2L = 0.821, logistic regression = 0.820, SVGP = 0.819, XGBoost = 0.785, and random forest = 0.774. However, with only \(\approx 104\) positive examples in the 6,000-observation test set (1.73% prevalence), bootstrap 95% CIs span approximately \(\pm 0.04\) — and the intervals for all six models overlap substantially (Section 6.11). No pairwise ROC-AUC difference is statistically significant at this test-set size. The tentative two-tier pattern — GP/DGP family at 0.819–0.823 versus tree-based ensembles at 0.774–0.785 — is consistent across all four GP models and represents a reversal from the credit-card result where XGBoost led, consistent with the GP kernel’s smooth non-parametric structure better capturing the monotonic FICO/LTV/DTI risk relationships. Confirming this reversal would require a larger test set.

Logistic regression’s strong showing (ROC-AUC = 0.820, tied second with DSVGP-2L to three decimal places) is consistent with long-standing findings in the mortgage credit-risk literature, where simple scorecard-like linear models often perform competitively due to the approximately monotonic relationships between the primary risk drivers and default (Thomas 2000). However, as the calibration analysis below demonstrates, logistic regression’s discriminative adequacy masks severe probability estimation failures.

Average precision — a metric that gives more weight to correctly ranking positive examples and is thus sensitive to model quality in the rare-event tail — tells a clearer story of GP advantage: DSVGP-2L = 0.084, DSVGP-3L = 0.082, logistic regression = 0.081, SVGP = 0.079, random forest = 0.062, XGBoost = 0.059. The GP family consistently concentrates its ranking quality in the critical positive-class region.

On threshold-dependent F1, logistic regression leads at 0.153 (\(t^* = 0.81\)), followed by random forest at 0.143 (\(t^* = 0.24\)) and SVGP at 0.141 (\(t^* = 0.07\)). However, F1 values in the 0.13–0.15 range are inherently low for all models and reflect the fundamental difficulty of the task at 1.73% prevalence rather than meaningful performance differences. The spread of 0.025 between the best and worst F1 is far less informative than the ROC-AUC and calibration differences.

6.2.3.2 Probability Calibration

The calibration advantage of GP and DGP models is dramatically amplified on the mortgage dataset relative to the credit-card benchmark. At a 1.73% base rate, small absolute errors in predicted probabilities translate to large relative distortions: a model that predicts 5% default probability when the true rate is 1.7% is overestimating risk by nearly \(3\times\), with direct capital cost implications under IRB.

DSVGP-2L achieves ECE = 0.002, SVGP = 0.003, DSVGP-3L = 0.004 — all effectively perfect calibration given the estimation uncertainty at this sample size. Random forest (ECE = 0.055) occupies a middling position, while logistic regression (ECE = 0.337) and XGBoost (ECE = 0.400) are severely miscalibrated. XGBoost’s ECE of 0.400 means that its predicted probabilities deviate from observed frequencies by an average of 40 percentage points per quantile bin — an order-of-magnitude failure that makes its raw probability outputs unusable for PD estimation without extensive post-hoc calibration.

The GP family achieves ECE values approximately 100\(\times\) lower than XGBoost (0.003 vs 0.400) and 170\(\times\) lower than logistic regression (0.002 vs 0.337). These ratios are far larger than the 12–13\(\times\) advantage seen on the credit-card dataset, demonstrating that the calibration benefit of the Bayesian posterior is proportionally greater when the true event rate is low. At a 1.73% base rate, the sigmoid-linked GP posterior correctly concentrates prediction mass near the base rate with appropriate uncertainty, while classical models’ point-estimate decision functions produce scores that are poorly aligned with the rare-event target distribution.

The Brier score and log loss reinforce this picture. GP models achieve Brier = 0.016–0.017 and log loss = 0.075–0.076, while classical baselines range from 0.023–0.186 (Brier) and 0.114–0.555 (log loss). The GP log loss is approximately \(7\times\) lower than XGBoost’s, reflecting the severe penalty that the logarithmic scoring rule imposes on confident but incorrect probability predictions (Bernardo and Smith 2000).

Under Basel IRB, PD estimates must track observed default rates within rating-grade buckets, and regulators increasingly validate calibration through ECE-like tests (European Banking Authority 2017). An ECE of 0.400 (XGBoost) or 0.337 (logistic regression) would fail any reasonable supervisory calibration standard. In contrast, GP models with ECE \(\leq 0.004\) produce probability estimates that are directly usable for regulatory capital calculation, IFRS 9 provisions (International Accounting Standards Board 2014), and stress-testing submissions without requiring a post-hoc calibration stage, which itself introduces additional model risk under SR 11-7 (Board of Governors of the Federal Reserve System 2011).

The question of whether post-hoc calibration could close this gap for classical models is important. Platt scaling (Platt 1999) or isotonic regression (Zadrozny and Elkan 2002) could potentially improve the ECE of XGBoost and logistic regression. However, this introduces three practical concerns: (1) the calibration mapping requires a held-out calibration set, reducing the training budget available for the base model; (2) the calibration layer is itself a model component that must be independently validated, governed, and monitored under supervisory frameworks such as SR 11-7 (Board of Governors of the Federal Reserve System 2011); and (3) for low-default portfolios where positive examples are scarce, the calibration set may contain too few defaults to reliably fit the calibration mapping. GP models avoid all three concerns by providing native calibration from the Bayesian posterior.

6.2.4 Scaling Behaviour Across Training Set Sizes

ROC and precision-recall curves and reliability diagrams at each training tier are provided in Section 6.9.

6.2.4.1 Discriminative Scaling

The scaling patterns on the mortgage dataset are broadly consistent with the credit-card findings but with important differences driven by the low base rate.

SVGP dominates at small scale. With only 425 training observations, SVGP achieves ROC-AUC = 0.764 — the highest of any model at any small-scale setting across both datasets. This is a 0.064 advantage over random forest and DSVGP-2L (both 0.692) and a 0.044 advantage over logistic regression (0.720). The single-layer GP’s inductive bias through the kernel function and the variational framework’s implicit regularisation provide a strong prior for the smooth risk surface of the mortgage domain, even with extremely limited training data.

DGP architectures are data-hungry. DSVGP-2L achieves only 0.692 at small scale — the same as random forest — then surges to 0.815 at medium scale and 0.821 at large scale, a gain of +0.129. This is the largest absolute ROC-AUC improvement of any model across tiers on either dataset, confirming that the compositional flexibility of multi-layer GP architectures requires sufficient data to train the inter-layer mappings effectively. DSVGP-3L again collapses at small scale (0.510, near-random) and recovers to 0.813/0.823 at medium/large — the same pathological behaviour observed on the credit-card dataset and consistent with Duvenaud et al. (2014).

Classical scaling. Logistic regression shows the strongest classical scaling response: ROC-AUC = 0.720 (small) to 0.820 (large), a gain of +0.100. This is larger than its credit-card gain (+0.023), suggesting that the mortgage feature space contains exploitable monotonic structure that benefits from more data. XGBoost improves by +0.085 (0.700 → 0.785), while random forest gains +0.082 (0.692 → 0.774). Both tree ensembles underperform the GP family at every scale on this dataset.

6.2.4.2 Calibration Scaling

GP models achieve near-perfect calibration from 425 observations. SVGP’s ECE is 0.008 at small scale, 0.001 at medium, and 0.003 at large. DSVGP-2L follows a similar trajectory (0.006 → 0.002 → 0.002). The medium-tier ECE values of 0.001–0.002 represent calibration indistinguishable from perfect at this sample size. This is a remarkable finding: even with only 425 training examples drawn from a 1.73%-prevalence population (approximately 7–8 positive examples), the Bayesian posterior’s uncertainty propagation produces well-calibrated probability estimates.

Classical calibration is unstable and non-monotonic. Logistic regression’s ECE worsens from 0.118 (small) to 0.328 (medium) to 0.337 (large). XGBoost exhibits even more erratic calibration (0.319 → 0.180 → 0.400). This non-monotonic behaviour arises because additional training data allows classical models to fit more extreme score distributions without an intrinsic mechanism to constrain probabilities toward calibrated values (Niculescu-Mizil and Caruana 2005). Random forest remains the best-calibrated classical model (ECE = 0.044–0.055 across tiers) due to the same bagging-induced smoothing effect described in Section 6.1.3.2, but it is still 10–25\(\times\) worse than the GP family.

6.2.5 Computational Profile

The computational profile mirrors the credit-card findings. DSVGP-3L at 650.2 s is the most expensive model, approximately \(3.9\times\) the cost of DSVGP-2L (167.8 s), yet its ROC-AUC advantage over DSVGP-2L is only +0.002 (0.823 vs 0.821) and its ECE is slightly worse (0.004 vs 0.002). SVGP provides the best cost-effectiveness among GP models: at 148.7 s it delivers ROC-AUC = 0.819 and ECE = 0.003, within 0.004 ROC-AUC of the best model at less than one-quarter the training cost of DSVGP-3L.

6.2.6 Discussion

Discriminative performance. The mortgage dataset produces a different ordering from the credit-card benchmark. GP and DGP models lead on ROC-AUC point estimates — DSVGP-3L (0.823) > DSVGP-2L (0.821) > LR (0.820) > SVGP (0.819) > XGB (0.785) > RF (0.774) — though as established in Section 6.2.3.1, none of these differences are statistically significant. The ordering is consistent with the theoretical expectation that kernel-based models capture smooth monotonic relationships (FICO, LTV, DTI) more directly than piecewise-constant tree partitions (Rasmussen and Williams 2008).

Probability calibration. The mortgage dataset provides the strongest evidence for the native calibration advantage of GP and DGP models. At a 1.73% base rate, GP models achieve ECE = 0.002–0.004 — essentially perfect calibration — while classical models produce ECE = 0.055–0.400. This 100\(\times\) calibration advantage is directly transferable to regulatory capital adequacy: GP-produced PD estimates can be used without adjustment in Basel IRB capital formulae (“Basel III: A Global Regulatory Framework for More Resilient Banks and Banking Systems” 2011), IFRS 9 expected credit loss calculations (International Accounting Standards Board 2014), and stress-testing models, whereas classical models require a post-hoc calibration stage. In practice, the calibration stage introduces both development cost and an additional validation burden under SR 11-7 model risk management requirements (Board of Governors of the Federal Reserve System 2011), making the GP’s native calibration a material operational simplification.

Practical implications. The Freddie Mac results carry direct consequences for production mortgage PD modelling:

  • Capital efficiency. A model with ECE = 0.002 (DSVGP-2L) produces PD estimates that closely match observed default rates at every risk grade. Under the IRB formula, where capital requirements scale with PD, this means capital charges accurately reflect portfolio risk. In contrast, XGBoost’s ECE of 0.400 implies systematic mis-estimation that would either over-capitalise (wasting resources) or under-capitalise (exposing the bank to regulatory action) depending on the direction of miscalibration across rating grades.

  • Threshold selection in practice. The optimal thresholds for GP models (\(t^* \approx 0.07\)–\(0.09\)) might appear operationally inconvenient, but they are in fact the natural consequence of well-calibrated predictions: if the true default rate is 1.7%, a good model’s optimal decision boundary should indeed lie well below 0.5. In production deployment, the decision threshold would be set based on the specific cost structure — the relative cost of granting credit to a future defaulter versus rejecting a creditworthy borrower — rather than by convention. GP models’ calibrated outputs are directly amenable to this expected-cost framework because their probabilities have the correct interpretation as genuine default frequencies.

  • Limitations. Despite their calibration advantage, GP models’ absolute discriminative performance (ROC-AUC = 0.819–0.823) leaves substantial room for improvement. In mortgage credit risk, where many relevant features capture time-varying macroeconomic conditions (interest rate environment, house price trajectories), incorporating temporal dynamics through recurrent or sequential model extensions could improve discriminative power. Additionally, the F1 values in the 0.13–0.15 range indicate that even the best models achieve limited precision at useful recall levels — a consequence of the low base rate rather than a modelling deficiency, but a practical constraint for applications requiring direct default prediction rather than risk ranking.

Architecture depth. On the mortgage dataset, the three-layer DGP achieves a +0.002 point-estimate ROC-AUC improvement over the two-layer variant — a tentative signal, the first time across both datasets, that deeper compositional structure may suit the structured mortgage feature space. However, the improvement is small relative to the \(3.9\times\) computational cost increase (650 s vs 168 s), and DSVGP-3L’s ECE (0.004) is slightly worse than DSVGP-2L’s (0.002). At small scale, DSVGP-3L again collapses (ROC-AUC = 0.510), reproducing the Duvenaud et al. (2014) pathology seen on the credit-card data. The evidence does not support using three-layer architectures for mortgage PD estimation.

GP vs DGP. The single-layer SVGP provides an excellent cost-calibration trade-off on this dataset. At large scale, its ROC-AUC (0.819) is within 0.004 of the best DGP (within the noise established in Section 6.2.3.1) and its ECE (0.003) is near-indistinguishable from DSVGP-2L’s (0.002). At small scale, SVGP dramatically outperforms both DGP architectures on point estimates (0.764 vs 0.692/0.510), a gap that is statistically significant given the wider FM CIs still separate 0.764 from 0.510. The additional compositional flexibility of the DGP primarily manifests at medium-to-large scale, where DSVGP-2L’s +0.003 ROC-AUC advantage over SVGP at large scale represents a marginal and statistically unresolvable gain. For mortgage PD applications where model simplicity and small-sample robustness are valued — as is typically the case for low-default portfolios — the single-layer SVGP is the more defensible choice.

Cross-dataset comparison. Comparing the mortgage and credit-card results reveals a consistent pattern: GP models are competitive or superior on discrimination and dramatically superior on calibration in both settings, but the magnitude of the advantage is amplified on the low-default mortgage dataset. The calibration advantage grows from 12–13\(\times\) (credit card, 22.1% default rate) to 100–170\(\times\) (mortgage, 1.73% default rate), consistent with the Bayesian interpretation that the posterior’s uncertainty quantification becomes more valuable as the prediction target moves further from 0.5 and classical models’ implicit assumptions about score-to-probability mappings break down more severely (Niculescu-Mizil and Caruana 2005). This finding carries a direct practical implication: the lower the default rate in a portfolio, the greater the relative advantage of GP models for producing regulatory-grade PD estimates.

6.3 Design Matrix Construction

With \(\mathbf{y} = [y_1, \ldots, y_n]^\top\) and the design matrix \(\Phi \in \mathbb{R}^{n \times M}\) where \(\Phi_{ij} = \phi_j(\mathbf{x}_i)\), the \(i\)-th row of \(\Phi\) is \(\boldsymbol{\phi}(\mathbf{x}_i)^\top\). The vector of predicted means is therefore

\[ \begin{bmatrix} \boldsymbol{\phi}(\mathbf{x}_1)^\top \mathbf{w} \\ \vdots \\ \boldsymbol{\phi}(\mathbf{x}_n)^\top \mathbf{w} \end{bmatrix} = \begin{bmatrix} \boldsymbol{\phi}(\mathbf{x}_1)^\top \\ \vdots \\ \boldsymbol{\phi}(\mathbf{x}_n)^\top \end{bmatrix} \mathbf{w} = \Phi \mathbf{w}. \tag{73}\]

6.4 Completing the Square for the Posterior over Weights

Starting from the log-posterior of the Bayesian linear regression model (ignoring terms independent of \(\mathbf{w}\)):

\[ \log p(\mathbf{w} \mid \mathbf{X}, \mathbf{y}) \propto -\frac{1}{2\sigma_n^2}(\mathbf{y} - \Phi\mathbf{w})^\top(\mathbf{y} - \Phi\mathbf{w}) - \frac{1}{2}\mathbf{w}^\top \Sigma_p^{-1}\mathbf{w}, \]

expanding the quadratic in \(\mathbf{y} - \Phi\mathbf{w}\) and collecting terms in \(\mathbf{w}\) gives

\[ -\frac{1}{2}\mathbf{w}^\top\!\bigl(\sigma_n^{-2}\Phi^\top\Phi + \Sigma_p^{-1}\bigr)\mathbf{w} + \sigma_n^{-2}\mathbf{y}^\top\Phi\,\mathbf{w} + \text{const}. \tag{74}\]

We verify that this can be written as \(-\frac{1}{2}(\mathbf{w} - \bar{\mathbf{w}})^\top \Sigma_w^{-1} (\mathbf{w} - \bar{\mathbf{w}})\) plus terms independent of \(\mathbf{w}\), which identifies the posterior as Gaussian with mean \(\bar{\mathbf{w}}\).

Expanding the squared form gives

\[ \begin{aligned} -\frac{1}{2}(\mathbf{w} - \bar{\mathbf{w}})^\top \Sigma_w^{-1} (\mathbf{w} - \bar{\mathbf{w}}) &= -\frac{1}{2}(\mathbf{w}^\top - \bar{\mathbf{w}}^\top) \Sigma_w^{-1} (\mathbf{w} - \bar{\mathbf{w}}) \\ &= -\frac{1}{2}\mathbf{w}^\top \Sigma_w^{-1} \mathbf{w} + \frac{1}{2}\mathbf{w}^\top \Sigma_w^{-1} \bar{\mathbf{w}} + \frac{1}{2}\bar{\mathbf{w}}^\top \Sigma_w^{-1} \mathbf{w} - \frac{1}{2}\bar{\mathbf{w}}^\top \Sigma_w^{-1} \bar{\mathbf{w}}. \end{aligned} \]

Since \(\Sigma_w^{-1}\) is symmetric, we have \(\bar{\mathbf{w}}^\top \Sigma_w^{-1} \mathbf{w} = \mathbf{w}^\top \Sigma_w^{-1} \bar{\mathbf{w}}\), so the two middle terms combine to give

\[ -\frac{1}{2}(\mathbf{w} - \bar{\mathbf{w}})^\top \Sigma_w^{-1} (\mathbf{w} - \bar{\mathbf{w}}) = -\frac{1}{2}\mathbf{w}^\top \Sigma_w^{-1} \mathbf{w} + \mathbf{w}^\top \Sigma_w^{-1} \bar{\mathbf{w}} - \frac{1}{2}\bar{\mathbf{w}}^\top \Sigma_w^{-1} \bar{\mathbf{w}}. \tag{75}\]

Comparing the linear term in \(\mathbf{w}\) from Equation 74 with Equation 75, we require

\[ \mathbf{w}^\top \Sigma_w^{-1} \bar{\mathbf{w}} = \sigma_n^{-2}\mathbf{y}^\top \Phi \mathbf{w}. \tag{76}\]

Writing the left side as \((\Sigma_w^{-1} \bar{\mathbf{w}})^\top \mathbf{w}\) and the right side as \((\sigma_n^{-2}\Phi^\top \mathbf{y})^\top \mathbf{w}\), and noting this must hold for all \(\mathbf{w}\), we get \(\Sigma_w^{-1} \bar{\mathbf{w}} = \sigma_n^{-2}\Phi^\top \mathbf{y}\), which gives the posterior mean \(\bar{\mathbf{w}} = \sigma_n^{-2} \Sigma_w \Phi^\top \mathbf{y}\) as stated in Equation 9.

6.5 Predictive Mean and Variance via Linear Transformation

Since \(f_* = \boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w}\) is a linear function of \(\mathbf{w} \mid \mathbf{X}, \mathbf{y} \sim \mathcal{N}(\bar{\mathbf{w}}, \Sigma_w)\), both the mean and variance follow from standard results for linear transformations of Gaussian random variables (Murphy 2013).

Mean:

\[ \begin{aligned} \mathbb{E}[f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}] &= \mathbb{E}[\boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w} \mid \mathbf{X}, \mathbf{y}] \\ &= \boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbb{E}[\mathbf{w} \mid \mathbf{X}, \mathbf{y}] \\ &= \boldsymbol{\phi}(\mathbf{x}_*)^\top \bar{\mathbf{w}} \\ &= \sigma_n^{-2} \boldsymbol{\phi}(\mathbf{x}_*)^\top \Sigma_w \Phi^\top \mathbf{y}. \end{aligned} \]

Variance:

\[ \begin{aligned} \operatorname{Var}[f_* \mid \mathbf{x}_*, \mathbf{X}, \mathbf{y}] &= \operatorname{Var}[\boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w} \mid \mathbf{X}, \mathbf{y}] \\ &= \mathbb{E}[(\boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w} - \boldsymbol{\phi}(\mathbf{x}_*)^\top \bar{\mathbf{w}})^2 \mid \mathbf{X}, \mathbf{y}] \\ &= \boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbb{E}[(\mathbf{w} - \bar{\mathbf{w}})(\mathbf{w} - \bar{\mathbf{w}})^\top \mid \mathbf{X}, \mathbf{y}]\, \boldsymbol{\phi}(\mathbf{x}_*) \\ &= \boldsymbol{\phi}(\mathbf{x}_*)^\top \Sigma_w \boldsymbol{\phi}(\mathbf{x}_*). \end{aligned} \]

6.6 Covariance Blocks of the Joint Distribution

With \(\mathbf{y} = \Phi\mathbf{w} + \boldsymbol{\epsilon}\) where \(\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \sigma_n^2\mathbf{I})\) is independent of \(\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \Sigma_p)\), and \(f_* = \boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w}\), the three covariance blocks are computed as follows.

Output covariance: \[ \begin{aligned} \operatorname{Cov}[\mathbf{y}, \mathbf{y}] &= \operatorname{Cov}[\Phi\mathbf{w} + \boldsymbol{\epsilon}, \Phi\mathbf{w} + \boldsymbol{\epsilon}] \\ &= \Phi\operatorname{Cov}[\mathbf{w}]\Phi^\top + \operatorname{Cov}[\boldsymbol{\epsilon}, \boldsymbol{\epsilon}] \\ &= \Phi\Sigma_p\Phi^\top + \sigma_n^2\mathbf{I}. \end{aligned} \]

Cross-covariance (noise \(\boldsymbol{\epsilon}\) is independent of \(f_*\)): \[ \begin{aligned} \operatorname{Cov}[\mathbf{y}, f_*] &= \operatorname{Cov}[\Phi\mathbf{w} + \boldsymbol{\epsilon},\, \boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{w}] \\ &= \Phi\operatorname{Cov}[\mathbf{w}]\boldsymbol{\phi}(\mathbf{x}_*) = \Phi\Sigma_p\boldsymbol{\phi}(\mathbf{x}_*). \end{aligned} \]

Test-point variance:

\[ \operatorname{Cov}[f_*, f_*] = \boldsymbol{\phi}(\mathbf{x}_*)^\top\operatorname{Cov}[\mathbf{w}]\boldsymbol{\phi}(\mathbf{x}_*) = \boldsymbol{\phi}(\mathbf{x}_*)^\top\Sigma_p\boldsymbol{\phi}(\mathbf{x}_*). \]

6.7.1 Multi-Tier Split Protocol

Both datasets use the same tiered evaluation design. A fixed 20% test set is stratified-sampled once from the full dataset; the remaining 80% forms the development pool. 6.7.2 Pre-Processing Pipeline

The DataPreprocessor class handles categorical encoding, numeric scaling, and split construction. The scaler is fit on the training set only and applied to validation and test sets, preventing leakage.

@staticmethod
def _encode_categoricals(X: pd.DataFrame) -> pd.DataFrame:
    """SEX → binary; EDUCATION and MARRIAGE → one-hot (drop_first=True)."""
    X = X.copy()
    if "SEX" in X.columns:
        X["SEX"] = X["SEX"].map({1: 0, 2: 1}).astype(int)  # 1=male→0, 2=female→1
    ohe_cols = [c for c in ["EDUCATION", "MARRIAGE"] if c in X.columns]
    if ohe_cols:
        X = pd.get_dummies(X, columns=ohe_cols, drop_first=True, dtype=int)
    return X

def fit_transform(self, X: pd.DataFrame) -> pd.DataFrame:
    """Fit encoders/scaler on X (training set) and return transformed copy."""
    X_enc = self._encode_categoricals(X)
    num_cols = [c for c in _NUMERIC if c in X_enc.columns]
    self._numeric_cols = num_cols
    self._scaler = StandardScaler()
    X_enc = X_enc.copy()
    X_enc[num_cols] = self._scaler.fit_transform(X_enc[num_cols].astype(float))
    return X_enc

def transform(self, X: pd.DataFrame) -> pd.DataFrame:
    """Apply the already-fitted scaler to a new split (no re-fitting)."""
    X_enc = self._encode_categoricals(X)
    X_enc = X_enc.reindex(columns=self._encoded_cols, fill_value=0)  # align dummies
    X_enc = X_enc.copy()
    X_enc[self._numeric_cols] = self._scaler.transform(
        X_enc[self._numeric_cols].astype(float)
    )
    return X_enc

The _NUMERIC constant covers LIMIT_BAL, AGE, the six PAY_* ordinal repayment-status codes, six BILL_* amounts, and six PAY_AMT_* repayment amounts. The same DataPreprocessor interface is used for Freddie Mac, extended with additional feature columns.

6.7.3 Post-Hoc Calibration Utility

A post-hoc calibration module is available for Platt scaling and isotonic regression but is not used in the default pipeline. The main text discusses why: post-hoc calibration introduces additional model risk under SR 11-7 (Board of Governors of the Federal Reserve System 2011), requires a held-out calibration set (reducing training data), and is difficult to validate on low-default portfolios. The code is included here for completeness:

def fit_probability_calibrator(
    method: str,
    y_prob: np.ndarray,
    y_true: np.ndarray,
) -> FittedCalibrator:
    """Fit a post-hoc calibrator from predicted probabilities."""
    probs = np.clip(np.asarray(y_prob, dtype=float), 1e-6, 1.0 - 1e-6)
    targets = np.asarray(y_true, dtype=int)
    if method == "platt":
        logits = np.log(probs / (1.0 - probs)).reshape(-1, 1)
        model = LogisticRegression(solver="lbfgs", random_state=42)
        model.fit(logits, targets)
        return FittedCalibrator(method=method, model=model)
    if method == "isotonic":
        model = IsotonicRegression(out_of_bounds="clip")
        model.fit(probs, targets)
        return FittedCalibrator(method=method, model=model)

6.7.4 SVGP Training Loop

optimizer = torch.optim.Adam(

    lr=self.lr,

mll = VariationalELBO(self._likelihood, self._model, num_data=len(y))

        loss   = -mll(output, y_batch)
        loss.backward()
        optimizer.step()

This is standard mini-batch stochastic variational inference for a sparse GP classifier. The variational ELBO is optimised jointly over the inducing-point representation and the Bernoulli likelihood parameters.

6.7.5 DSVGP Training Loop

optimizer = torch.optim.Adam(self._model.parameters(), lr=self.lr)

train_samples = min(self.num_samples, 10)

for epoch in range(1, self.n_epochs + 1):
    for X_batch, y_batch in _iter_batches(X, y, self.batch_size):
        X_batch = X_batch.to(self.device)
        y_batch = y_batch.to(self.device)

        with gpytorch.settings.num_likelihood_samples(train_samples):
            optimizer.zero_grad()
            output = self._model(X_batch)
            loss   = -mll(output, y_batch)
            loss.backward()
            optimizer.step()

This is the doubly stochastic variational setup used for the deep GP models. The first source of stochasticity is mini-batch optimisation; the second is Monte Carlo sampling through the layered latent structure via num_likelihood_samples. The deep GP experiments in this dissertation use the DSVI-style training approach of Salimbeni and Deisenroth (2017).

6.7.6 Optimal Threshold Re-computation

After training, metrics are re-computed at each model’s F1-optimal threshold rather than the conventional \(t = 0.5\). The threshold search scans \([0.01, 0.99]\) at granularity \(\Delta t = 0.001\):

def find_optimal_threshold(y_true, y_prob, metric="f1", lo=0.01, hi=0.99,
                           step=0.001):
    thresholds = np.arange(lo, hi + step, step)
    best_t, best_v = 0.5, 0.0
    for t in thresholds:
        y_pred = (y_prob >= t).astype(int)
        if metric == "f1":
            v = f1_score(y_true, y_pred, zero_division=0.0)
        if v > best_v:
            best_v, best_t = v, t
    return best_t, best_v

This is particularly important for the Freddie Mac dataset (1.73% default rate), where GP models produce well-calibrated probabilities concentrated near the base rate, requiring \(t^* \approx 0.07\)–\(0.09\), while classical models require \(t^* \approx 0.24\)–\(0.81\).
